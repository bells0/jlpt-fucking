### 35-1 もっとも・しかも

#### 原题完整记录（不要加工）

题目说明：

> 次の文の（　）に入れるのに最もよいものを、1、2、3、4から一つ選びなさい。

题干：

> 今日、子どもをきつくしかりすぎたので、気をつけようと思う。（　）、本人はそれほど気にしていないかもしれないが。

选项：

1. そのかわり
2. それなら
3. もっとも
4. しかも

你的答案 / 正解：

- 你的答案: 4. しかも
- 正解: 3. もっとも

#### 解析

正解：

> もっとも

意思是：“今天我把孩子骂得太重了，所以想以后注意一点。不过话虽如此，本人可能并没有那么在意。”

整句翻译：

> 今天我把孩子骂得太重了，所以我想以后要注意一点。不过，孩子本人也许并没有那么在意。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `今日` | 今天 | 时间名词 |
| `子どもを` | 把孩子…… | `を` 表示动作对象 |
| `きつく` | 严厉地、重重地 | 这里的 `きつい` 不是“紧”，而是“严厉、重” |
| `しかりすぎた` | 骂过头了、训得太重了 | `しかる` + `すぎる` |
| `ので` | 因为……所以…… | 说明后面想法的原因 |
| `気をつけようと思う` | 我想以后注意一点 | `〜ようと思う` 表示“想着要……、打算……” |
| `もっとも` | 不过、话虽如此 | 对前面的判断做补充修正 |
| `本人は` | 本人、当事人 | 这里指“孩子本人” |
| `それほど` | 那么、那种程度上 | 常和否定搭配，表示“并没有那么……” |
| `気にしていない` | 没有放在心上、没有太在意 | `気にする` = 在意、介意 |
| `かもしれない` | 也许、可能 | 表示说话人的推测 |
| `が` | 不过……、可是…… | 句尾留有保留语气，比直接断句更柔和 |

整句逻辑：

1. `今日、子どもをきつくしかりすぎたので`
   因为今天把孩子骂得太重了。
2. `気をつけようと思う`
   所以我觉得以后要注意一点。
3. `もっとも、本人はそれほど気にしていないかもしれないが`
   不过，孩子本人也许并没有那么在意。

这里前半句是“自我反省”，后半句是“补一句保留”。所以 `もっとも` 很自然，`しかも` 不对，因为 `しかも` 是“而且、进一步加强前面的内容”，不是“给前面的判断降一点强度”。

| 选项 | 用法 | 为什么不合适 |
|---|---|---|
| そのかわり | 作为替代、相反补偿 | 前后不是交换关系 |
| それなら | 如果那样的话 | 不是承接对方条件 |
| もっとも | 不过、话虽如此 | 正好表示补充修正 |
| しかも | 而且、并且 | 后句不是加强前句，而是对前句降温 |

记忆点：

- `もっとも` = “话是这么说，不过...”
- `しかも` = “而且还...”，通常让前面内容更强。
- 看到前面先有一个判断，后面再补一句“不过也未必完全如此”，优先想 `もっとも`。

例句：

> この作戦は危険だ。もっとも、成功すれば大きな成果が得られる。

### 35-2 かりに...とすると

#### 原题完整记录（不要加工）

题目说明：

> 次の文の（　）に入れるのに最もよいものを、1、2、3、4から一つ選びなさい。

题干：

> 人は通勤に多くの時間を使っている。（　）通勤に往復2時間かけるとすると、1年間で480時間も通勤に使っている計算になる。

选项：

1. たとえ
2. かりに
3. ようやく
4. かえって

你的答案 / 正解：

- 你的答案: 1. たとえ
- 正解: 2. かりに

#### 解析

正解：

> かりに

整句翻译：

> 假如往返通勤要花 2 个小时来算，那么一年里光通勤就要花 480 个小时。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `人は通勤に多くの時間を使っている` | 人们花很多时间在通勤上 | 先总说事实 |
| `かりに` | 假设、假如 | 设定条件用语 |
| `通勤に往復2時間かけるとすると` | 如果算往返通勤要花 2 小时的话 | `とすると` 表示“假设这样的话” |
| `1年間で480時間も` | 一年里竟然有 480 小时 | `も` 强调数量大 |
| `通勤に使っている計算になる` | 算下来都花在通勤上了 | `計算になる` = 计算下来会变成... |

这里是在“假设往返通勤花 2 小时”的条件下做计算。

| 选项 | 核心意思 | 常见搭配 |
|---|---|---|
| たとえ | 即使 | `たとえ...ても` |
| かりに | 假设、假如 | `かりに...とすると / としても` |
| ようやく | 终于 | 用于结果终于实现 |
| かえって | 反而 | 结果与预期相反 |

易错点：

- `たとえ` 后面通常需要逆接：`たとえ雨が降っても行く。`
- 本题是设定条件再计算，所以用 `かりに`。

例句：

> かりに毎日30分復習するとすると、1か月で15時間になる。

### 36 使おうとしたら

#### 原题完整记录（不要加工）

题目说明：

> 次の文の（　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

题干：

> 懐中電灯を（　）、電池が切れていて、つかなかった。

选项：

1. 使おうとしたら
2. 使うようにしたら
3. 使おうとするなら
4. 使うようにするなら

你的答案 / 正解：

- 你的答案: 4. 使うようにするなら
- 正解: 1. 使おうとしたら

#### 解析

正解：

> 使おうとしたら

整句翻译：

> 正想拿手电筒来用时，发现电池没电了，亮不了。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `懐中電灯を` | 把手电筒 | 动作对象 |
| `使おうとしたら` | 正想用的时候 | 表示“准备做某事时” |
| `電池が切れていて` | 电池已经没电了 | `切れている` = 没电、断掉 |
| `つかなかった` | 没有亮起来 | 结果句 |

意思是：“正想用手电筒的时候，发现电池没电了，亮不了。”

| 表达 | 意思 | 重点 |
|---|---|---|
| Vようとしたら | 正要做某事时，发生/发现了某事 | 后面常接意外情况 |
| Vようにしたら | 如果设法/改成做某事 | 强调调整习惯或方法 |
| Vようとするなら | 如果打算做某事 | 偏“要做的话” |
| Vようにするなら | 如果要养成/安排成某状态 | 本题不自然 |

例句：

> セーブしようとしたら、ゲームが急に止まった。

作品场景钩子：

像游戏里角色“正要开手电探索地下室”，结果发现没电。这里不是“如果使用”，而是“正要使用的瞬间发现问题”。

### 40-1 や何かで

#### 原题完整记录（不要加工）

题目说明：

> 次の文の（　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

题干：

> A「ねえ見て、このゲーム。面白そうだから、買っちゃった。」
> B「あ、それって、最近雑誌（　）よく取り上げられてるゲームでしょう？」

选项：

1. か何かを
2. や何かで
3. か何かか
4. や何かは

你的答案 / 正解：

- 你的答案: 4. や何かは
- 正解: 2. や何かで

#### 解析

正解：

> や何かで

整句翻译：

> 啊，那是不是最近经常在杂志之类的地方被介绍的游戏呢？

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `最近` | 最近 | 时间副词 |
| `雑誌や何かで` | 在杂志之类的地方 | `や何かで` 表示“之类的媒介/场合” |
| `よく` | 经常、常常 | 程度副词 |
| `取り上げられてる` | 被介绍、被报道 | 被动表达 |
| `ゲームでしょう` | 应该是那个游戏吧 | 推测判断 |

意思是：“那是不是最近在杂志之类的地方经常被介绍的游戏？”

| 形式 | 用法 | 本题判断 |
|---|---|---|
| 名詞や何かで | 在...之类的媒介/场合中 | 正解 |
| 名詞か何かを | ...或者什么东西作为宾语 | 后面不能接 `取り上げられてる` |
| 名詞か何かか | 是...还是什么吗 | 结构不接后文 |
| 名詞や何かは | ...之类的东西作为主题 | 与被动动词搭配不自然 |

例句：

> そのアニメは、SNSや何かでよく話題になっている。

考试抓法：

看到 `取り上げられている / 紹介されている / 話題になっている`，前面常需要表示“媒介、场所”的 `で`。

### 41 使いたいだけ

#### 原题完整记录（不要加工）

题目说明：

> 次の文の（　）に入れるのに最もよいものを1・2・3・4から一つ選びなさい。

题干：

> 先月、エアコンを（　）使っていたら、電気代が2万円を超えてしまった。

选项：

1. 使いすぎて
2. 使ったまま
3. 使いたいだけ
4. 使いつづけたり

你的答案 / 正解：

- 你的答案: 1. 使いすぎて
- 正解: 3. 使いたいだけ

#### 解析

正解：

> 使いたいだけ

整句翻译：

> 上个月空调怎么想开就怎么开，结果电费竟然超过了 2 万日元。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `先月` | 上个月 | 时间 |
| `エアコンを` | 空调 | 动作对象 |
| `使いたいだけ` | 想怎么用就怎么用 | `たいだけ` = 尽情、随心所欲地 |
| `使っていたら` | 如果一直那么用 / 用着用着 | 这里接后果 |
| `電気代が2万円を超えてしまった` | 电费超过了 2 万日元 | `〜てしまう` 带遗憾、结果超出预期 |

意思是：“上个月想怎么开空调就怎么开，结果电费超过了 2 万日元。”

| 表达 | 意思 | 区别 |
|---|---|---|
| VたいだけV | 想怎么 V 就怎么 V；尽情 V | 强调不节制 |
| Vすぎて | 太 V，所以... | 后面通常直接接结果，不适合插在 `使っていたら` 前 |
| Vたまま | 保持 V 后的状态 | `使ったまま` 是“用了以后保持原状”，不等于一直开 |
| Vつづけたり | 持续做、反复做之类 | 后面结构不完整 |

例句：

> 休日にゲームをしたいだけしていたら、宿題が終わらなかった。

记忆点：

- `たいだけ` 有“放任自己”的感觉。
- 看到后面有坏结果，常考“想怎么...就怎么...”导致结果失控。

### 40-2 書いても書かなくても

题目说明：

题干：

> 毎日（　）どちらでもいいことばかりを日記に書いているのだが、それがストレス解消になっている。

选项：

1. 書くとも書かないとも
2. 書いたか書かなかったか
3. 書いても書かなくても
4. 書くとか書かないとか

你的答案 / 正解：

- 你的答案: スクリーンショット未显示
- 正解: スクリーンショット未显示（旧解析参考: 3. 書いても書かなくても）

#### 解析

旧解析参考：

> 書いても書かなくても

整句翻译：

> 每天我都把些写也行、不写也行的事情记在日记里，不过这反倒成了我的减压方式。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `毎日` | 每天 | 时间副词 |
| `書いても書かなくても` | 写也行、不写也行 | `ても〜なくても` = 做也行不做也行 |
| `どちらでもいいことばかり` | 净是些无所谓的事 | “写不写都可以”的内容 |
| `日記に書いている` | 写在日记里 | 动作 |
| `それがストレス解消になっている` | 那反而成了减压 | 结果句 |

意思是：“每天把那些写也行、不写也行的小事写进日记，不过这反而成了我的解压方式。”

固定感：

> VてもVなくても、どちらでもいい

常译为：“做也行，不做也行。”

| 选项 | 判断 |
|---|---|
| 書くとも書かないとも | 多用于“既不说写，也不说不写”：`書くとも書かないとも言わない` |
| 書いたか書かなかったか | 是否写过，强调过去事实 |
| 書いても書かなくても | 正合 `どちらでもいい` |
| 書くとか書かないとか | 表示“说要写啦不写啦之类”，偏列举话题 |

例句：

> 参加してもしなくても、どちらでもいいです。

### 32 受け入れる

2. 入口でパンフレットを受け入れてから席にお座りください

你的答案 / 正解：

- 正解: スクリーンショット未显示（旧解析参考: 3. 私の大学では、毎年大勢の留学生を受け入れています）

#### 解析

旧解析参考：

> 私の大学では、毎年大勢の留学生を受け入れています。

整句翻译：

> 在我的大学里，每年都会接收大量留学生。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `私の大学では` | 在我的大学里 | 场所 |
| `毎年` | 每年 | 时间副词 |
| `大勢の留学生を` | 大量留学生 | 动作对象 |
| `受け入れています` | 接收、接纳 | 现在进行/习惯性行为 |

### 词汇整理

| 项目 | 内容 |
|---|---|
| 読み方 | うけいれる |
| 词性 | 他动词・一段动词 |
| 核心意思 | 接纳、接受、容纳 |
| 常见宾语 | 人、意见、事实、文化、制度 |

常见搭配：

- `留学生を受け入れる`：接收留学生
- `意見を受け入れる`：接受意见
- `現実を受け入れる`：接受现实
- `異文化を受け入れる`：接纳异文化

易混词：

| 词 | 意思 | 例句 |
|---|---|---|
| 受け入れる | 接纳、接受 | 留学生を受け入れる |
| 受け付ける | 受理申请、挂号、接受预约 | 申し込みを受け付ける |
| 受け取る | 收到、领取 | パンフレットを受け取る |
| 取り入れる | 引进、采纳、吸收 | 最新技術を取り入れる |

截图选项判断：

- `チケットのお申し込みは電話で受け入れています` → 应为 `受け付けています`
- `パンフレットを受け入れてから席に...` → 应为 `受け取ってから`
- `留学生を受け入れています` → 正确
- `最新の技術を受け入れた製品` → 通常说 `最新の技術を取り入れた製品`

### 38 うちに

#### 解析

旧解析参考：

> うちに

整句翻译：

> 这首歌一开始我不太喜欢，但反复听着听着，渐渐就喜欢上了。

整句拆解：

| 片段 | 意思 | 说明 |
|---|---|---|
| `最初はあまり好きではなかったが` | 一开始不太喜欢，不过... | 前半句 |
| `何度も聞いているうちに` | 听着听着、反复听的过程中 | 表示过程中的变化 |
| `だんだん好きになってきた` | 渐渐变喜欢了 | 结果变化 |

意思是：“这首歌一开始没那么喜欢，但听着听着就渐渐喜欢上了。”

| 选项 | 意思 | 本题判断 |
|---|---|---|
| なかに | 在...里面 | 不能接这种变化过程 |
| うちに | 在...期间；在做的过程中 | 正解 |
| ついでに | 顺便 | 无“逐渐变化” |
| とたんに | 刚一...就突然... | 强调瞬间，不是渐渐 |

核心句型：

> Vているうちに、だんだん...

表示“在持续做某事的过程中，不知不觉发生变化”。

例句：

> 最初は難しかったが、毎日読んでいるうちに、少しずつ分かるようになった。

## 集中复习：这组错题的共同陷阱

### 1. 接续词不是只看中文意思，要看前后逻辑

| 表达 | 中文感 | 真正逻辑 |
|---|---|---|
| もっとも | 不过、话虽如此 | 补充限制、修正 |
| しかも | 而且 | 进一步追加、加强 |
| それなら | 那样的话 | 接住前面的条件 |
| そのかわり | 取而代之、作为补偿 | 交换、替代 |

### 2. 假设表达要看后面搭配

| 表达 | 常见句型 | 例句 |
|---|---|---|
| たとえ | たとえ...ても | たとえ失敗しても、諦めない。 |
| かりに | かりに...とすると | かりに1日1時間勉強するとすると... |

### 3. 「よう」相关题要抓动作时点

| 形式 | 中文 | 例句 |
|---|---|---|
| Vようとしたら | 正要做时 | 電話しようとしたら、電池が切れた。 |
| Vようにする | 设法做到、养成习惯 | 毎日復習するようにしている。 |
| Vようとするなら | 如果打算做 | 本気で合格しようとするなら、復習が必要だ。 |

### 4. 助词决定句子角色

这次 `や何かで` 错在 `で`。`雑誌やSNSで取り上げられる` 里的 `で` 是“媒介/场所”。

对比：

- `雑誌で紹介される`
- `SNSで話題になる`
- `テレビで取り上げられる`

### 5. 变化过程常考「うちに」

看到这些词时优先想到 `うちに`：

- `だんだん`
- `少しずつ`
- `いつの間にか`
- `Vている`
