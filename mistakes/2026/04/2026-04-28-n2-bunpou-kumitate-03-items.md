### 45 大手商社に比べると、決して規模は大きくないが

#### 原题完整记录（不要加工）

题干：

> 私が就職した商社は、大手 ＿＿ ＿＿ ★ ＿＿ 新人でも大きな仕事を任せてもらえるので、やりがいがある。

#### 原题排序形式

> 大手 ＿＿ ＿＿ ★ ＿＿ 新人でも大きな仕事を任せてもらえるので、やりがいがある。

#### 选项

1. 決して
2. 商社に比べると
3. やる気があれば
4. 規模は大きくないが

#### 你的答案 / 正解

- 你的答案: 3. やる気があれば
- 正解: 4. 規模は大きくないが

#### 正确顺序

> 2 → 1 → 4 → 3

#### ★答案

> 4. 規模は大きくないが

#### 还原过程

> 大手 [2]商社に比べると、[1]決して [★=4]規模は大きくないが、[3]やる気があれば 新人でも...

这里 ★ 的位置是第 3 个空，所以答案是 `規模は大きくないが`。

#### 解析

完整句：

> 私が就職した商社は、大手商社に比べると、決して規模は大きくないが、やる気があれば新人でも大きな仕事を任せてもらえるので、やりがいがある。

意思：

> 我就职的商社和大型商社相比，规模绝不算大，但是只要有干劲，即使是新人也能被交给重要工作，所以很有意义。

高频考点：

| 表达 | 意思 | 用法 |
|---|---|---|
| `Aに比べると` | 和 A 相比 | 后面接比较结果 |
| `決して...ない` | 绝不... | 必须和否定形式一起用 |
| `規模が大きい / 小さい` | 规模大 / 小 | 公司、学校、活动常用 |
| `やる気があれば` | 如果有干劲 | 条件句 |
| `仕事を任せてもらう` | 被交给工作、得到负责工作的机会 | `任せる` 是“交给、委托” |

错因：

- 你选了 `やる気があれば`，它确实能接后面的 `新人でも...`。
- 但星号位置需要先完成前面的让步句：`決して規模は大きくないが`。
- 这题要先找大结构：`Aに比べると、決してBではないが、CならD`。

下次抓法：

> 看到 `大手` 后面如果有 `に比べると`，后面常接“比较结果”。这里就是 `規模は大きくないが`。

例句：

> このチームは強豪校に比べると、決して経験は多くないが、集中力なら負けない。

### 49-1 政治に対する信頼があって初めて

#### 原题完整记录（不要加工）

题干：

> 国民の、政治 ＿＿ ＿＿ ★ ＿＿ 政治家は指導力を発揮できるのだ。

#### 原题排序形式

> 政治 ＿＿ ＿＿ ★ ＿＿ 政治家は指導力を発揮できるのだ。

#### 选项

1. 初めて
2. に対する
3. があって
4. 信頼

#### 你的答案 / 正解

- 你的答案: 2. に対する
- 正解: 3. があって

#### 正确顺序

> 2 → 4 → 3 → 1

#### ★答案

> 3. があって

#### 还原过程

> 政治 [2]に対する [4]信頼 [★=3]があって [1]初めて、政治家は...

这里 ★ 的位置是第 3 个空，所以答案是 `があって`。

#### 解析

完整句：

> 国民の、政治に対する信頼があって初めて、政治家は指導力を発揮できるのだ。

意思：

> 只有国民对政治有信任，政治家才能发挥领导力。

高频考点：

| 表达 | 意思 | 用法 |
|---|---|---|
| `Nに対するN` | 对 N 的... | 后面必须接名词 |
| `信頼` | 信任、信赖 | 常见搭配：`信頼がある`、`信頼を失う` |
| `Nがあって初めて...` | 有了 N 之后才... | 强调前提条件 |
| `指導力を発揮する` | 发挥领导力 | `能力を発揮する` 也常见 |

错因：

- 你选了 `に対する`，但 `に対する` 必须先和后面的名词连起来：`政治に対する信頼`。
- `信頼` 后面需要谓语成分：`信頼があって`。
- `初めて` 常和前面的条件一起构成：`Aがあって初めてB`。

固定结构：

> Nがあって初めて、B。

表示“正因为有 A，B 才成立”。

例句：

> 仲間の協力があって初めて、この計画は成功する。

> 基礎文法の理解があって初めて、長い文章も読めるようになる。

### 49-2 毎朝しているジョギングのおかげだ

#### 原题完整记录（不要加工）

题干：

> 母は「風邪をひかないのは、＿＿ ＿＿ ★ ＿＿」とよく言っている。

#### 原题排序形式

> ＿＿ ＿＿ ★ ＿＿

#### 选项

1. ジョギングの
2. している
3. おかげだ
4. 毎朝

#### 你的答案 / 正解

- 你的答案: 2. している
- 正解: 1. ジョギングの

#### 正确顺序

> 4 → 2 → 1 → 3

#### ★答案

> 1. ジョギングの

#### 还原过程

> [4]毎朝 [2]している [★=1]ジョギングの [3]おかげだ

这里 ★ 的位置是第 3 个空，所以答案是 `ジョギングの`。

#### 解析

完整句：

> 母は「風邪をひかないのは、毎朝しているジョギングのおかげだ」とよく言っている。

意思：

> 母亲常说：“我不感冒，是多亏了每天早上做的慢跑。”

高频考点：

| 表达 | 意思 | 用法 |
|---|---|---|
| `毎朝` | 每天早上 | 时间副词，修饰动作 |
| `Vている + 名词` | 正在/长期做的... | `しているジョギング` 修饰名词 |
| `ジョギング` | 慢跑 | 外来语，常和 `する` 搭配 |
| `Nのおかげだ` | 多亏 N | 多用于好结果 |
| `風邪をひく` | 感冒 | 固定搭配 |

错因：

- 你选了 `している`，但 `している` 要先修饰后面的名词。
- 正确结构是：`毎朝しているジョギング`。
- 然后整体接 `のおかげだ`：`毎朝しているジョギングのおかげだ`。

固定结构：

> Nのおかげだ

表示“多亏了 N”。通常是好的结果。

例句：

> 毎日続けている復習のおかげで、文法問題が少し楽になった。

> 先生のアドバイスのおかげで、読解の解き方が分かってきた。

## 这 3 题共同的错因

| 错因 | 说明 | 下次怎么做 |
|---|---|---|
| 只看局部能不能接 | 选项局部能接，不代表星号位置正确 | 先还原整句骨架 |
| 没先找固定结构 | `があって初めて`、`Nのおかげだ` 都是强结构 | 看到熟悉尾巴先反推前面 |
| 修饰关系没抓住 | `毎朝している` 修饰 `ジョギング` | 动词普通形后面常修饰名词 |
| 让步结构断开 | `決して規模は大きくないが` 是一个完整让步块 | `が` 前后要分别成句 |

## 迷你复习题

按排序题的形式做。先不要看答案。

### 题目

1. この会社は大企業 ＿＿ ＿＿ ★ ＿＿ 若手にも大きな仕事を任せてくれる。
   1. 規模は大きくないが
   2. に比べると
   3. 決して
   4. やる気があれば

2. 彼は、周り ＿＿ ＿＿ ★ ＿＿ 走り切ることができた。
   1. 初めて
   2. の支え
   3. 最後まで
   4. があって

3. 日本語が楽しくなったのは、＿＿ ＿＿ ★ ＿＿。
   1. 読んでいる
   2. 漫画の
   3. 毎日
   4. おかげだ

### 答案

1. 2 → 3 → 1 → 4。★ = 1 `規模は大きくないが`
2. 2 → 4 → 1 → 3。★ = 1 `初めて`
3. 3 → 1 → 2 → 4。★ = 2 `漫画の`
