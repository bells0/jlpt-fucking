## 错题解析

### 問題31

- 指示语：待复核
- 题干：水泳教室に通い始めたころは、怖くて水に顔をつけること（　）できなかったが、今は泳ぐのが大好きだ。
- 选项：1. ほど / 2. ばかり / 3. さえ / 4. なら
- 你的答案：2. ばかり
- 正解：3. さえ
- 中文翻译：刚开始上游泳课时，害怕得连把脸放进水里都做不到，但现在非常喜欢游泳。
- 错因：这里要举出最低限度、极端的小事，表示“连……都”。`ばかり` 是“光是、净是”，不表示这种极端例示。
- 下次怎么判断：看到 `こと（　）できない`，且前面是很小的动作，优先想 `さえできない`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000020-bunpou-31-options.png]]

### 問題32

- 题干：この作業はかなり大変なので、一日で終わらせるのは（　）無理だろう。
- 选项：1. たとえ / 2. まず / 3. 今に / 4. つい
- 你的答案：1. たとえ
- 正解：2. まず
- 中文翻译：这个工作相当辛苦，一天内完成恐怕不太可能。
- 错因：`たとえ` 后面要接让步条件，如 `たとえ〜ても`。本题需要副词 `まず` 表示“大概、恐怕、基本上”。
- 下次怎么判断：`まず無理だろう` 是固定感很强的判断表达。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000022-bunpou-32.png]]

### 問題34

- 题干：この図書館には、借りている本を全部（　）、ほかの本が借りられないという規則がある。
- 选项：1. 返したとはいえ / 2. 返したすえに / 3. 返してからでないと / 4. 返してはじめて
- 你的答案：4. 返してはじめて
- 正解：3. 返してからでないと
- 中文翻译：这家图书馆有规定，不先还完已借的书，就不能借其他书。
- 错因：后项是 `借りられない` 否定结果，最自然的是 `〜てからでないと〜ない`。
- 下次怎么判断：看到“不先 A 就不能 B”，直接套 `AてからでないとBない`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000023-bunpou-34-options.png]]

### 問題37

- 题干：この研究を始めたころは、そんなことを研究して意味が（　）批判的な意見も多かったが、最近少しずつ認めてもらえるようになってきた。
- 选项：1. あるのかというような / 2. あるというような / 3. あるのかということの / 4. あるということの
- 你的答案：4. あるということの
- 正解：1. あるのかというような
- 中文翻译：刚开始做这项研究时，也有很多“研究那种事有什么意义吗”这样的批评意见，但最近渐渐获得了认可。
- 错因：批判的意见本身是疑问质疑 `意味があるのか`，后面修饰 `批判的な意見` 要用 `というような`。
- 下次怎么判断：`意味があるのか` 是“有没有意义啊？”这种质疑语气，不要改成肯定句。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000025-bunpou-37-options.png]]

### 問題38

- 题干：腕のけがはまだ完全に（　）が、日常生活には困らなくなった。
- 选项：1. 治ったわけではない / 2. 治りようがない / 3. 治らないでもない / 4. 治ったにすぎない
- 你的答案：4. 治ったにすぎない
- 正解：1. 治ったわけではない
- 中文翻译：胳膊的伤还不是完全好了，但日常生活已经不受影响了。
- 错因：后半是“日常不困扰”，前半应是部分否定“并不是完全好了”。`にすぎない` 表示“只不过”，语义不合。
- 下次怎么判断：`完全に〜わけではない` = 并非完全……。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000027-bunpou-38.png]]

### 問題39

- 题干：私は20年前に初めて富士山に登った。山頂に立ったときの感動は今でも（　）。
- 选项：1. 忘れがたい / 2. 忘れかけている / 3. 忘れるおそれがある / 4. 忘れないといい
- 你的答案：4. 忘れないといい
- 正解：1. 忘れがたい
- 中文翻译：我 20 年前第一次登上富士山。站在山顶时的感动至今仍难以忘怀。
- 错因：题干是回忆仍很深，不是祝愿“希望别忘”。`Vます形 + がたい` 表示“难以……”。
- 下次怎么判断：`感動は今でも` 后面常接 `忘れがたい`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000028-bunpou-39.png]]

### 問題40

- 题干：洗濯機に入れるときに気づいたからよかったが、もう少しで大事な領収書をズボンのポケットに入れたまま（　）。
- 选项：1. 洗濯するつもりだった / 2. 洗濯するところだった / 3. 洗濯したようだ / 4. 洗濯したせいだ
- 你的答案：1. 洗濯するつもりだった
- 正解：2. 洗濯するところだった
- 中文翻译：幸好放进洗衣机时发现了，差一点就把重要收据放在裤兜里一起洗了。
- 错因：`もう少しで` 提示差点发生某事，用 `〜ところだった`，不是“打算洗”。
- 下次怎么判断：`もう少しで + Vるところだった` = 差一点就……。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000029-bunpou-40-options.png]]

### 問題41

- 题干：毎晩私は、5歳の娘が寝る前にベッドで本を読んでやるのだが、読んでいるうちに自分のほうが（　）。
- 选项：1. 寝ておくことにする / 2. 寝ておくことがある / 3. 寝てしまうことがある / 4. 寝てしまうことにする
- 你的答案：2. 寝ておくことがある
- 正解：3. 寝てしまうことがある
- 中文翻译：每晚我都会在 5 岁女儿睡前给她读书，但读着读着有时反而是我睡着了。
- 错因：这里是“不由得睡着了”的结果，用 `〜てしまう`；`寝ておく` 是“先睡着备用”，不自然。
- 下次怎么判断：不小心发生、结果不受控制，用 `〜てしまう`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000031-bunpou-41.png]]

### 問題44

- 题型：文の組み立て
- 题干：娘「今度のスピーチコンテスト、参加しようかなあ。でも、自信ないなあ。」母「チャレンジ ＿＿ ＿＿ ★ ＿＿？いい経験になると思うよ。」
- 选项：1. だけ / 2. みたら / 3. して / 4. する
- 你的答案：2. みたら
- 正解：3. して
- 正确顺序：4 → 1 → 3 → 2
- 还原句：チャレンジするだけしてみたら？いい経験になると思うよ。
- 中文翻译：要不要先挑战看看？我觉得会是一次很好的经验。
- 错因：`するだけしてみる` 是整体，“能试的先试试看”。`★` 落在第三空，对应 `して`。
- 下次怎么判断：排序题先还原固定结构，再数 `★` 的位置。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000032-bunpou-44-options.png]]

### 問題45

- 题型：文の組み立て
- 题干：このドレスを着ると、＿＿ ＿＿ ★ ＿＿ 気分になる。
- 选项：1. なったような / 2. お姫様にでも / 3. 映画か何かに / 4. 出てくる
- 你的答案：3. 映画か何かに
- 正解：2. お姫様にでも
- 正确顺序：3 → 4 → 2 → 1
- 还原句：このドレスを着ると、映画か何かに出てくるお姫様にでもなったような気分になる。
- 中文翻译：穿上这条裙子，就会有一种仿佛变成电影之类作品里出现的公主的心情。
- 错因：`映画か何かに出てくる` 整体修饰 `お姫様`，`〜にでもなったような気分` 是后半骨架。
- 下次怎么判断：长修饰先找被修饰名词，这题是 `お姫様`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000034-bunpou-45.png]]

### 問題47

- 题型：文の組み立て
- 题干：学生時代は、周りのひとから ＿＿ ＿＿ ★ ＿＿ 無理して人に合わせようとすることが多かった。
- 选项：1. 言えずに / 2. 自分の本当の気持ちを / 3. 自分がどう思われているかを / 4. 気にするあまり
- 你的答案：3. 自分がどう思われているかを
- 正解：2. 自分の本当の気持ちを
- 正确顺序：3 → 4 → 2 → 1
- 还原句：学生時代は、周りのひとから自分がどう思われているかを気にするあまり自分の本当の気持ちを言えずに無理して人に合わせようとすることが多かった。
- 中文翻译：学生时代，我常常因为太在意周围人怎么看自己，而说不出真实想法，勉强迎合别人。
- 错因：`〜を気にするあまり` 后面要接消极结果；`自分の本当の気持ちを言えずに` 是结果小句。
- 下次怎么判断：看到 `あまり`，先找“过度原因 → 消极结果”。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000035-bunpou-47.png]]

### 問題49・50・51 共用原文

- 指示语：次の文章を読んで、48から51の中に入る最もよいものを、1・2・3・4から一つ選びなさい。
- 原文：

```text
以下は、留学生の作文である。

農業ボランティア
ゴメスフランシスコ

半年前、私は友達に誘われて、働き手が足りない農家を手伝う「農業ボランティア」を始めた。過去にごみ拾いなどのボランティアはしたことがあったが、農業ボランティアのことは友達に聞くまで知らなかった。私は日本でいろいろな経験をしたいと思っていたので、参加することにした。

わたしが手伝っているのは南さんという農家だ。40代の夫婦がトマトやキャベツなど、いろいろな野菜を作っている。農作業は初めての経験だったが、農業は想像していた以上に知識や経験が必要だと感じた。48、収穫のタイミングは、成長の具合や天気予報をもとに、いつがいいかを判断しなければならない。また、トマトなどは成長の段階に応じて与える水の量を変えないとしっかり育たない。体力49必要で、農業は本当に大変な仕事だ。

収穫したばかりのトマトを初めて食べさせてもらったときはあまりにおいしくて50。収穫したときの達成感や大切に育てた野菜を味わう喜びは、このボランティアに参加しなければ感じられなかっただろう。

農業として役に立てたことが嬉しかったし、多くの貴重な経験をすることができます。51本当に良かったと思う。
```

#### 問題49

- 题干：体力（　）必要で、農業は本当に大変な仕事だ。
- 选项：1. だけ / 2. も / 3. は / 4. こそ
- 你的答案：3. は
- 正解：2. も
- 中文翻译：体力也很必要，农业真的是很辛苦的工作。
- 错因：前文已经说农业需要知识和经验，这里追加“体力也需要”，应选并列追加的 `も`。
- 下次怎么判断：前后同类信息追加，用 `も`；`は` 偏对比，题干没有把体力拿来与别的东西对比。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000036-bunpou-49.png]]

#### 問題50

- 题干：収穫したばかりのトマトを初めて食べさせてもらったときはあまりにおいしくて（　）。
- 选项：1. 感動していた / 2. 感動してしまった / 3. 感動したはずだ / 4. 感動したことだ
- 你的答案：1. 感動していた
- 正解：2. 感動してしまった
- 判定依据：稳定详情页中 1 旁为红叉、2 旁为绿勾；`回顧` 显示 4，但与视觉状态冲突，按视觉状态记录。
- 中文翻译：第一次吃到刚收获的番茄时，因为太好吃了，不由得感动了。
- 错因：这里强调“意料之外地自然产生感情”，用 `〜てしまった`。`感動していた` 只是持续状态，不符合“太好吃以至于……”的结果。
- 下次怎么判断：`あまりに〜くて` 后面常接自然结果；感情突然涌出可用 `〜てしまう`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000038-bunpou-50-51.png]]

#### 問題51

- 题干：（　）本当に良かったと思う。
- 选项：1. やってみたら / 2. やってみて / 3. やってみても / 4. やってみたから
- 你的答案：1. やってみたら
- 正解：2. やってみて
- 判定依据：稳定详情页中 1 旁为红叉、2 旁为绿勾；`回顧` 显示 3，但与视觉状态冲突，按视觉状态记录。
- 中文翻译：我觉得尝试去做这件事真的太好了。
- 错因：`やってみてよかった` 是固定评价“做了之后觉得很好”。`たら` 是假设条件，不适合总结实际体验。
- 下次怎么判断：表达“做过之后觉得好”，用 `Vてよかった`。
- 截图：![[mistakes/assets/2026-06-27/Screenshot_20260627_000039-bunpou-51-stable.png]]

## 综合错因

| 错因 | 对应题 | 复盘动作 |
|---|---|---|
| 固定句型没有整体识别 | 34、39、40、44、51 | 把 `てからでないと`、`がたい`、`ところだった`、`するだけしてみる`、`てよかった` 当成整块记。 |
| 只按中文大意选 | 32、38、49、50 | 先判断句子功能：判断、部分否定、追加、自然结果。 |
| 排序题修饰关系没抓住 | 45、47 | 先找被修饰名词和谓语骨架，再数 `★`。 |
| 文章语法前后文照应弱 | 49、50、51 | 空格不只看所在句，还要看前一两句的逻辑。 |
| `回顧` 与视觉状态冲突时需要复核 | 50、51 | 重新从答题卡点开题目，以红叉/绿勾为主。 |

## 迷你复习题

### 問題

1. この作業を一日で終わらせるのは（　）無理だろう。
2. 借りている本を全部返して（　）、ほかの本は借りられない。
3. もう少しで領収書を入れたまま洗濯する（　）。
4. 体力（　）必要で、農業は本当に大変だ。
5. チャレンジする（　）してみたら？

### 答案

1. `まず`
2. `からでないと`
3. `ところだった`
4. `も`
5. `だけ`

## 复盘总结

这批文法的核心不是“不会翻译”，而是句子功能判断慢：看到空格时先问自己，它是在追加、否定、条件、感情结果，还是排序里的修饰骨架。
