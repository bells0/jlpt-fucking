## 错题解析

### 問題1

**原题完整记录**

- 指示语: ____の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 状況を<u>詳細</u>に書いてください。
- 选项: 1. しょうざい / 2. しょうさい / 3. そうさい / 4. そうざい
- 你的答案: 4. そうざい
- 正解: 2. しょうさい

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | しょうざい | `詳細` 不读浊音 `ざい`，是干扰音。 |
| 2 | しょうさい | 正解。`詳細`，详细；常用 `詳細に説明する`、`詳細を書く`。 |
| 3 | そうさい | 不是 `詳細` 的读音；容易被 `詳` 的形近感带偏。 |
| 4 | そうざい | 不是 `詳細` 的读音；`総菜（そうざい）` 是“熟食、菜肴”。 |

**中文翻译**: 请详细写下情况。  
**错因**: 漢字音读不稳，把 `詳` 的 `しょう` 误看成 `そう`。  
**下次怎么判断**: 看到 `詳細` 整词背 `しょうさい`，不要拆字猜。

### 問題3

**原题完整记录**

- 指示语: ____の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 髪の毛が櫛（くし）に<u>絡まって</u>しまった。
- 选项: 1. からまって / 2. つまって / 3. たまって / 4. はさまって
- 你的答案: 4. はさまって
- 正解: 1. からまって

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | からまって | 正解。`絡まる`，缠住、纠缠；`髪が絡まる`、`コードが絡まる`。 |
| 2 | つまって | `詰まる`，堵住、塞满；`鼻が詰まる`、`予定が詰まる`。不表示头发缠在梳子上。 |
| 3 | たまって | `溜まる`，积攒；`疲れが溜まる`、`水が溜まる`。 |
| 4 | はさまって | `挟まる`，夹住；`ドアに指が挟まる`。头发和梳子是缠绕，不是夹住。 |

**中文翻译**: 头发缠在梳子上了。  
**错因**: 方向或动作词混淆，按“被卡住”选了 `挟まる`。  
**下次怎么判断**: 线、头发、绳子纠缠成一团，用 `絡まる`。

### 問題4

**原题完整记录**

- 指示语: ____の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: ここでは<u>農薬</u>をまったく使わずに野菜を栽培している。
- 选项: 1. のうらく / 2. のうやく / 3. のんらく / 4. のんやく
- 你的答案: 4. のんやく
- 正解: 2. のうやく

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | のうらく | 不是 `農薬` 的读音。 |
| 2 | のうやく | 正解。`農薬`，农药；`農薬を使う`、`無農薬野菜`。 |
| 3 | のんらく | 不是 `農薬` 的读音。 |
| 4 | のんやく | `農` 在这里读长音 `のう`，不读 `のん`。 |

**中文翻译**: 这里完全不使用农药来栽培蔬菜。  
**错因**: 長音 `のう` 没有整体记牢。  
**下次怎么判断**: `農業（のうぎょう）`、`農家（のうか）`、`農薬（のうやく）` 成组背。

### 問題6

**原题完整记录**

- 指示语: ____の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: この会社を<u>しぼう</u>した理由を教えてください。
- 选项: 1. 希望 / 2. 貴望 / 3. 志望 / 4. 指望
- 你的答案: 4. 指望
- 正解: 3. 志望

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | きぼう | `希望`，希望；`希望する会社` 可以说，但 `会社をしぼうする` 应写 `志望`。 |
| 2 | きぼう | `貴望` 不是常用表记。 |
| 3 | しぼう | 正解。`志望`，志愿、报考/应聘意向；`志望校`、`志望理由`。 |
| 4 | しぼう | `指望` 在日语里不是本题自然表记；中文干扰强。 |

**中文翻译**: 请告诉我你应聘这家公司的理由。  
**错因**: 固定表记没记牢，被中文“指望”干扰。  
**下次怎么判断**: 学校、公司、专业的“志愿/意向”写 `志望`。

### 問題8

**原题完整记录**

- 指示语: ____の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 桜の花が<u>ちって</u>いくのを眺める。
- 选项: 1. 失って / 2. 消って / 3. 去って / 4. 散って
- 你的答案: 2. 消って
- 正解: 4. 散って

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | うしなって | `失う`，失去；不读 `ちる`。 |
| 2 | きえて | `消える` 写 `消えて`，不是 `消って`；语义是消失，不是花瓣飘落。 |
| 3 | さって | `去る`，离去；不读 `ちる`。 |
| 4 | ちって | 正解。`散る`，花落、散开；`桜が散る`。 |

**中文翻译**: 望着樱花渐渐飘落。  
**错因**: 固定表记没记牢，把“消失”语感套到花落。  
**下次怎么判断**: 花、叶、樱花落下固定用 `散る`。

### 問題10

**原题完整记录**

- 指示语: ____の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 最近あまり体調がよくないのは、<u>ひろう</u>のせいだろう。
- 选项: 1. 病老 / 2. 病労 / 3. 疲老 / 4. 疲労
- 你的答案: 2. 病労
- 正解: 4. 疲労

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | びょうろう | 不是 `ひろう` 的常用词。 |
| 2 | びょうろう | `病労` 不是本题表记。 |
| 3 | ひろう | `疲` 对，但 `老` 错；`疲老` 不自然。 |
| 4 | ひろう | 正解。`疲労`，疲劳；`疲労がたまる`、`疲労のせい`。 |

**中文翻译**: 最近身体状态不太好，大概是疲劳造成的吧。

### 問題12

**原题完整记录**

- 指示语: （　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 子どもたちの読書<u>（　）</u>が進んでいるらしい。
- 选项: 1. 離れ / 2. 抜け / 3. 逃げ / 4. 別れ
- 你的答案: 2. 抜け
- 正解: 1. 離れ

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | ばなれ | 正解。`〜離れ`，远离、脱离某事物；`若者の車離れ`、`読書離れ`。 |
| 2 | ぬけ | `〜抜け` 表示漏掉、脱落或穿过；`気が抜ける`、`トンネル抜け`，不接 `読書` 表趋势。 |
| 3 | にげ | `逃げ`，逃跑、逃避；不说 `読書逃げ`。 |
| 4 | わかれ | `別れ`，分别、离别；不表示社会趋势。 |

**中文翻译**: 孩子们远离阅读的趋势似乎在加剧。  
**错因**: 接尾词搭配弱。  
**下次怎么判断**: 社会群体“不再喜欢/不再接触某事物”用 `〜離れ`。

### 問題14

**原题完整记录**

- 指示语: （　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 両親はおいしい料理で客を<u>（　）</u>のが好きだ。
- 选项: 1. 許す / 2. もてなす / 3. 救う / 4. おだてる
- 你的答案: 4. おだてる
- 正解: 2. もてなす

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | ゆるす | `許す`，允许、原谅；不能说用料理“原谅客人”。 |
| 2 | もてなす | 正解。招待、款待；`客をもてなす`、`料理でもてなす`。 |
| 3 | すくう | `救う`，救助；与料理招待无关。 |
| 4 | おだてる | 奉承、哄；对象可为人，但和 `おいしい料理で客を...` 不搭。 |

**错因**: 动词宾语搭配不敏感。  
**下次怎么判断**: `客` + `料理` 的场景先想 `もてなす`。

### 問題18

**原题完整记录**

- 指示语: （　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 台風で電車が運休になり、通勤や通学で利用する人に<u>（　）</u>影響を与えた。
- 选项: 1. 大まかな / 2. 多大な / 3. 偉大な / 4. 大げさな
- 你的答案: 4. 大げさな
- 正解: 2. 多大な

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | おおまかな | 粗略的；`大まかな説明`。不修饰 `影響を与える`。 |
| 2 | ただいな | 正解。巨大的、很大的；固定 `多大な影響`、`多大な迷惑`。 |
| 3 | いだいな | 伟大的；`偉大な人物`。不说 `偉大な影響を与えた`。 |
| 4 | おおげさな | 夸张的；`大げさな話`。影响本身不说夸张。 |

**错因**: 近义词只看中文“大”，没看固定搭配。

### 問題19

**原题完整记录**

- 指示语: （　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 西川さんは転校してきたばかりだが、友達もできて、もうすっかりクラスに<u>（　）</u>いる。
- 选项: 1. 溶け込んで / 2. 結びついて / 3. 触れ合って / 4. 当てはまって
- 你的答案: 3. 触れ合って
- 正解: 1. 溶け込んで

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | とけこんで | 正解。融入；`クラスに溶け込む`、`職場に溶け込む`。 |
| 2 | むすびついて | 联系、结合；`原因と結果が結びつく`，不表示融入班级。 |

### 問題24

**原题完整记录**

- 指示语: ____に意味が最も近いものを、1・2・3・4から一つ選びなさい。
- 题干: 使わない物は、ここに<u>収納して</u>ください。
- 选项: 1. 捨てて / 2. 預けて / 3. しまって / 4. 並べて
- 你的答案: 4. 並べて
- 正解: 3. しまって

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | すてて | 扔掉；与 `収納する` 相反。 |
| 2 | あずけて | 寄存、托管；`荷物を預ける`。不是放进收纳处。 |
| 3 | しまって | 正解。收起来、放回去；`引き出しにしまう`。 |
| 4 | ならべて | 排列；`本を並べる`。只表示排成列，不等于收纳。 |

**中文翻译**: 不用的东西请收在这里。  
**错因**: 只抓到“放置”大意，没区分 `収納` 的“收起来”。  
**下次怎么判断**: `収納する` 接近 `しまう`，不是 `並べる`。

### 問題28

**原题完整记录**

- 指示语: 次の言葉の使い方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: はきはき
- 选项:
  1. よく眠ったので、今日は頭が<u>はきはき</u>としている。
  2. ビルの屋上から、遠くの山が<u>はきはき</u>と見える。
  3. その学生は、聞かれたことに<u>はきはき</u>と答えた。
  4. ミスの原因を<u>はきはき</u>とさせるために、調査が行われた。
- 你的答案: 2.
- 正解: 3.

**选项意思和用法**

| 选项 | 说明 |
|---|---|
| 1 | 头脑清醒应说 `頭がすっきりしている`。`はきはき` 不修饰头脑状态。 |
| 2 | 远处山看得清楚应说 `はっきりと見える`。你的答案把 `はきはき` 和 `はっきり` 混了。 |
| 3 | 正解。`はきはきと答える`，回答清楚、干脆、有精神。 |
| 4 | 弄清原因应说 `原因をはっきりさせる`。 |

**中文翻译**: 那个学生对被问到的问题回答得很清楚干脆。  
**错因**: 拟态词搭配混淆，`はきはき` 与 `はっきり` 没分清。  
**下次怎么判断**: 人说话、回答、态度爽快用 `はきはき`；视觉清楚和原因明确用 `はっきり`。

## 综合错因

| 错因 | 本批次对应题 | 复盘动作 |
|---|---|---|
| 漢字音读不稳 | 1、4 | 把 `詳細`、`農薬` 当整词背。 |
| 固定表记没记牢 | 6、8、10 | 用完整搭配记：`志望理由`、`桜が散る`、`疲労のせい`。 |

## 迷你复习题

### 問題

1. 状況を（しょうさい）に説明する。漢字は？
2. 子どもの（読書＿＿）が進んでいる。
3. おいしい料理で客を＿＿。
4. 遠くの山が＿＿見える。`はきはき` / `はっきり`
5. 転校生がクラスにすっかり＿＿。

### 答え

1. 詳細
2. 読書離れ
3. もてなす
4. はっきり
5. 溶け込む

## 复盘总结

这批文字・語彙的核心不是“完全不认识”，而是把熟词读音、固定搭配和近义词语感混在一起了。下次看到题干，先抓固定搭配：`多大な影響`、`客をもてなす`、`クラスに溶け込む`。
