## 错题解析

### 問題4

**原题完整记录**

- 指示语: ____の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: すぐに<u>実践</u>できるとは思っていなかった。
- 选项: 1. じっげん / 2. じっけん / 3. じっせん / 4. じっぜん
- 你的答案: 1. じっげん
- 正解: 3. じっせん
- 判定依据: 1 旁为红叉，3 旁为绿勾。
- 截图: ![[mistakes/assets/2026-06-27/Screenshot_20260627_000019-goi-04.png]]

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | じっげん | 不是 `実践` 的读音；容易被 `実現（じつげん）` 干扰。 |
| 2 | じっけん | `実験` 的读音，意思是实验；不是实践。 |
| 3 | じっせん | 正解。`実践`，实行、实践；`理論を実践する`、`すぐ実践できる`。 |
| 4 | じっぜん | 不是常用读音。 |

**中文翻译**: 我没想到能马上实践。  
**错因**: 漢字音读不稳，把 `実践` 和 `実現`、`実験` 的音混在一起。  
**下次怎么判断**: 理论变行动是 `実践（じっせん）`；实验是 `実験（じっけん）`。

### 問題7

**原题完整记录**

- 指示语: ____の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 安全な場所に<u>ひなん</u>をしてください。
- 选项: 1. 被難 / 2. 避離 / 3. 避難 / 4. 被離
- 你的答案: 2. 避離
- 正解: 3. 避難
- 判定依据: 2 旁为红叉，3 旁为绿勾。
- 截图: ![[mistakes/assets/2026-06-27/Screenshot_20260627_000017-goi-07-08.png]]

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|
| 1 | ひなん | `被難` 不是本题表记；`被` 有“被受”的意思，不表示主动逃避危险。 |
| 2 | ひり | `避` 对，但 `離` 错；避开灾害固定写 `避難`。 |
| 3 | ひなん | 正解。`避難`，避难、逃难；`安全な場所に避難する`。 |
| 4 | ひり | 两个字都不能组成本题自然表记。 |

**中文翻译**: 请到安全的地方避难。  
**错因**: 固定表记没记牢，看到“离开危险”就误选 `離`。  
**下次怎么判断**: 灾害、危险、警报场景固定用 `避難する`。

**选项意思和用法**

| 选项 | 读音 | 说明 |
|---|---|---|

### 問題26

**原题完整记录**

- 指示语: 次の言葉の使い方として最もよいものを、1・2・3・4から一つ選びなさい。
- 题干: 薄める
- 选项:
  1. 部屋が暑かったので、エアコンをつけて温度を薄めた。
  2. 私には難しすぎたので、コースのレベルを薄めた。
  3. うるさいと言われたので、テレビの音量を薄めた。
  4. スープがしょっぱかったので、水を加えて味を薄めた。
- 你的答案: 2
- 正解: 4
- 判定依据: 2 旁为红叉，4 旁为绿勾。
- 截图: ![[mistakes/assets/2026-06-27/Screenshot_20260627_000014-goi-26.png]]

**选项意思和用法**

| 选项 | 句子意思 | 判断 |
|---|---|---|
| 1 | 房间太热，所以开空调把温度弄淡了。 | 不自然。温度用 `下げる`，不是 `薄める`。 |
| 2 | 对我来说太难，所以把课程水平弄淡了。 | 不自然。难度、水平用 `下げる`、`易しくする`。 |
| 3 | 被说太吵，所以把电视音量弄淡了。 | 不自然。音量用 `下げる`、`小さくする`。 |
| 4 | 汤太咸，所以加水把味道调淡了。 | 正解。`薄める` 用于浓度、味道、液体等变淡。 |

**中文翻译**: 汤太咸了，所以加水把味道调淡。  
**错因**: 只看中文“降低/变弱”，没有看 `薄める` 的对象通常是浓度、味道、液体。  
**下次怎么判断**: `味・濃度・スープ・薬品` 可以 `薄める`；温度、音量、水平用 `下げる`。

  1. 次回のセミナーの開催日はまだ鮮明に決まっていない。
  2. あのときの出来事は今でも鮮明に覚えている。
  3. できそうにない仕事は鮮明に断ったほうがいい。
  4. X社の製品のほうが性能が鮮明に優れている。
- 你的答案: 3
- 正解: 2
- 判定依据: 3 旁为红叉，2 旁为绿勾。
- 截图: ![[mistakes/assets/2026-06-27/Screenshot_20260627_000015-goi-28.png]]

**选项意思和用法**

| 选项 | 句子意思 | 判断 |
|---|---|---|
| 1 | 下次研讨会日期还没有鲜明地决定。 | 不自然。日期确定用 `はっきり決まる`。 |
| 2 | 那时发生的事至今还记得很清楚。 | 正解。`鮮明に覚えている` 表记忆、图像清晰。 |
| 3 | 做不了的工作最好鲜明地拒绝。 | 不自然。拒绝态度明确用 `はっきり断る`。 |
| 4 | X 公司产品性能鲜明地优越。 | 不自然。性能差异明显用 `明らかに優れている`。 |

**中文翻译**: 那时候发生的事情，我现在也记得很清楚。  
**错因**: 把 `鮮明` 当作所有“明确”的通用副词。  
**下次怎么判断**: `鮮明` 常用于记忆、印象、画面、色彩清晰；拒绝和决定用 `はっきり`。

## 综合错因

| 错因 | 本批次表现 | 复盘动作 |
|---|---|---|
| 漢字音读不稳 | `実践` 误读成接近 `実現` 的音 | 整词背 `実践・実験・実現`，不要临场拆字猜。 |
| 固定表记没记牢 | `避難`、`敬う`、`受講`、`宛て` | 用完整搭配记：`安全な場所に避難する`、`講座を受講する`。 |
| 近义词只看中文 | `修正=直す`、`徐々に=次第に`、`剥げる=取れる` | 看动作方向和变化过程，不只看中文近似。 |
| 搭配对象不敏感 | `口調で話す`、`味を薄める`、`鮮明に覚える` | 记「词 + 对象」：语气、味道、记忆。 |

## 迷你复习题

### 問題

1. `すぐに実践できる` 中 `実践` 的读音是？
2. `安全な場所に＿＿する`，表示避难。
3. `パソコン教室の講座を＿＿する`，表示参加课程。
4. `スープがしょっぱいので、水を加えて味を＿＿。`
5. `あのときの出来事は今でも＿＿に覚えている。`

### 答え

1. じっせん
2. 避難
3. 受講
4. 薄める
5. 鮮明

## 复盘总结

这批的关键词是「不要只看中文，要看对象」：课程是 `受講`，语气是 `口調`，味道才可以 `薄める`，记忆和画面才容易 `鮮明`。
