## 错题解析

### 1. 問題1

#### 原题完整记录（不要加工）

- 场景: （店で）
- 题干:
  - 客「すみません、この携帯電話を解約したいんですが。」
  - 店員「かしこまりました。差し支えなければ、解約の理由を（　）。」

#### 选项

1. お聞きになりますか
2. お聞きになったらいかがですか
3. お聞きしませんか
4. お聞きしてもよろしいでしょうか

#### 你的答案 / 正解

- 你的答案: 1. お聞きになりますか
- 正解: 4. お聞きしてもよろしいでしょうか

#### 中文翻译

- 客人: “不好意思，我想解约这部手机。”
- 店员: “明白了。如果方便的话，可以询问您解约的理由吗？”

#### 整句翻译

> 差し支えなければ、解約の理由をお聞きしてもよろしいでしょうか。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 差し支えなければ | 如果不妨碍的话、如果方便的话 | 很礼貌的前置缓冲 |
| 解約の理由を | 解约的理由 | `聞く` 的宾语 |
| お聞きしてもよろしいでしょうか | 我可以询问吗 | 自谦语 + 许可请求 |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| お聞きになりますか | `お + ます形 + になる`，尊敬语，表示对方听/问 | 不合适。店员是在说“我来问您”，要用自谦语 |
| お聞きになったらいかがですか | 尊敬语 + 建议，“您问问如何” | 不合适。不是建议客人去问别人 |
| お聞きしませんか | 自谦形式，但句尾像邀请“一起问吗” | 不自然。服务场景中要请求许可 |
| お聞きしてもよろしいでしょうか | 自谦语 + “可以……吗” | 正解。店员礼貌地请求允许自己询问 |

#### 高频考点

- `お + Vます形 + する`: 自谦语，说自己的动作。
- `お + Vます形 + になる`: 尊敬语，说对方或上级的动作。

#### 下次怎么判断

- 先判断动作主语：店员问客人理由，所以“问”的人是店员自己。
- 自己的动作要压低，用 `お聞きする`，再加 `てもよろしいでしょうか` 请求许可。

#### 例句

- お名前をお聞きしてもよろしいでしょうか。

### 2. 問題6

#### 原题完整记录（不要加工）

- 题干: 私は漫画ばかり読んでいると思われているようだが、そんなことはない。たまには小説を読むこと（　）ある。

#### 选项

1. だって
2. のほうが
3. のほかにも
4. なんて

#### 你的答案 / 正解

- 你的答案: 3. のほかにも
- 正解: 1. だって

#### 中文翻译

- 好像别人觉得我只看漫画，但其实不是那样。我偶尔也会读小说。

#### 整句翻译

> たまには小説を読むことだってある。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| たまには | 偶尔也 | 和“一直/总是”的印象对比 |
| 小説を読むこと | 读小说这件事 | 动作名词化 |
| だってある | 就连……也有 | 举出反例，反驳“只看漫画” |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| だって | `名詞 + だって`，就连……也；即使……也 | 正解。`小説を読むことだってある` = 读小说这种事也有 |
| のほうが | 比较，“……更……” | 不合适。后面没有比较对象和评价 |
| のほかにも | 除此之外还…… | 不合适。一般后面还要接别的内容，如 `小説のほかにも雑誌を読む` |
| なんて | 举例、轻视或惊讶，“……什么的” | 不合适。本句不是轻视“读小说” |

#### 高频考点

- `名詞 + だって`: 举出一个极端或被忽略的例子，表示“连……也”。

#### 下次怎么判断

- 看到前面有“そんなことはない”，后面往往会给反例。
- “漫画ばかりじゃない，小説も読む”这种反例适合 `だって`。

#### 例句

- ゲームばかりしていると思われているが、勉強することだってある。

### 3. 問題7

#### 原题完整记录（不要加工）

- 题干: 弟がスケートをするのが初めてだったので何度か転んでいたが、初めてにしては（　）上手だった。

#### 选项

1. ついに
2. なかなか
3. まさか
4. まもなく

#### 你的答案 / 正解

- 你的答案: 3. まさか
- 正解: 2. なかなか

#### 中文翻译

- 弟弟是第一次滑冰，所以摔了好几次，但以第一次来说，已经相当不错了。

#### 整句翻译

> 初めてにしてはなかなか上手だった。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 初めてにしては | 以第一次来说 | `Nにしては`，以该标准看有点超出预期 |
| なかなか | 相当、挺 | 修饰正面评价 |
| 上手だった | 很擅长、做得好 | 评价 |

#### 选项用法辨析

| 选项 | 意思 | 常见用法 | 本题判断 |
|---|---|---|---|
| ついに | 终于 | `ついに成功した` | 不合适。不是经过长时间终于达成 |
| なかなか | 相当、挺；也可与否定搭配表示不容易 | `なかなか上手だ`、`なかなか終わらない` | 正解。和 `上手` 搭配，表示评价比预想高 |
| まさか | 难道、没想到 | `まさか彼が来るとは` | 不合适。不能直接修饰 `上手だった` |
| まもなく | 不久、马上 | `まもなく始まる` | 不合适。表示时间，不修饰评价 |

#### 高频考点

- `Nにしては`: 按照某个身份、条件或标准来看，结果和一般预想不同。

#### 下次怎么判断

- 看到 `初めてにしては`，后面常接评价：`上手だ`、`よくできた`、`詳しい`。
- 评价偏正面时，`なかなか` 很常见。

#### 例句

- 初めて作った料理にしては、なかなかおいしかった。

### 4. 問題8

#### 原题完整记录（不要加工）

- 题干:
  - 妻「ねえ、この雑誌のアンケートに答えると、抽選で一人にテレビが当たるんだって。応募してみようよ。」
  - 夫「抽選で一人じゃ、（　）。」

#### 选项

1. 当たりますように
2. 当たるといいなあ
3. 当たらないくせに
4. 当たりっこないよ

#### 你的答案 / 正解

- 你的答案: 1. 当たりますように
- 正解: 4. 当たりっこないよ

#### 中文翻译

- 妻子: “听说回答这本杂志的问卷，会抽一人送电视。我们试着报名吧。”
- 丈夫: “只抽一个人的话，不可能中的啦。”

#### 整句翻译

> 抽選で一人じゃ、当たりっこないよ。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 抽選で一人じゃ | 抽奖只抽一个人的话 | `では` 的口语缩约 `じゃ` |
| 当たりっこないよ | 不可能中啦 | `Vます形 + っこない` |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| 当たりますように | 希望中奖，祈愿表达 | 不合适。丈夫是在泼冷水，不是在祈愿 |
| 当たるといいなあ | 要是中奖就好了 | 不合适。语气偏期待，与“一人じゃ”后的否定判断不合 |
| 当たらないくせに | 明明不会中却…… | 不合适。`くせに` 后面通常还要接责备内容 |
| 当たりっこないよ | 根本不可能中奖 | 正解。符合“只抽一个人”的判断 |

#### 高频考点

- `Vます形去ます + っこない`: 绝不可能……，口语强烈否定。

#### 下次怎么判断

- 看到 `一人じゃ`、`無理だ` 这种低概率语境，优先想 `っこない`。

#### 例句

- 今から走っても、電車に間に合いっこないよ。

### 5. 問題9

#### 原题完整记录（不要加工）

- 题干: 今回の戦略が有効であったかどうかは、まだ結果が出ていない現時点では（　）。

#### 选项

1. 判断せざるを得ない
2. 判断したにすぎない
3. 判断しかねる
4. 判断すべきだ

#### 你的答案 / 正解

- 你的答案: 截图红色选择: 1. 判断せざるを得ない / 回顾欄: 上一次的选择: 4. 判断すべきだ
- 正解: 3. 判断しかねる

#### 中文翻译

- 这次战略是否有效，在结果还没有出来的现阶段，很难判断。

#### 整句翻译

> まだ結果が出ていない現時点では判断しかねる。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 今回の戦略が有効であったかどうかは | 这次战略是否有效 | 判断对象 |
| まだ結果が出ていない現時点では | 在结果还没出来的现阶段 | 判断困难的理由 |
| 判断しかねる | 难以判断 | 正式表达 |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| 判断せざるを得ない | 不得不判断 | 不合适。句子说结果未出，不是“不得不判断” |
| 判断したにすぎない | 只不过判断了 | 不合适。前面不是在贬低某个已完成判断 |
| 判断しかねる | 难以判断、无法轻易判断 | 正解。和 `まだ結果が出ていない` 完全对应 |
| 判断すべきだ | 应该判断 | 不合适。不是提出义务或建议 |

#### 高频考点

- `Vます形去ます + かねる`: 难以……、不能轻易……。正式、委婉。

#### 下次怎么判断

- 看到 `まだ結果が出ていない`，判断类动词后优先想“难以判断”：`判断しかねる`。

#### 例句

- 詳しい資料がないため、今は回答しかねます。

### 6. 問題10

#### 原题完整记录（不要加工）

- 场景: （会社で）
- 题干:
  - 課長「山下さん、A社の木村様が（　）、応接室に案内してください。」
  - 山下「はい、わかりました。」

#### 选项

1. 参ったら
2. おいでになったら
3. おありだったら
4. 伺ったら

#### 你的答案 / 正解

- 你的答案: 截图红色选择: 1. 参ったら / 回顾欄: 上一次的选择: 4. 伺ったら
- 正解: 2. おいでになったら

#### 中文翻译

- 课长: “山下，A公司的木村先生到了的话，请带他去会客室。”
- 山下: “好的，明白了。”

#### 整句翻译

> A社の木村様がおいでになったら、応接室に案内してください。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| A社の木村様が | A公司的木村先生 | 外部客户，应使用尊敬语 |
| おいでになったら | 来了的话 | `来る` 的尊敬语 |
| 応接室に案内してください | 请带去会客室 | 指示山下的动作 |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| 参ったら | `行く/来る` 的自谦语 | 不合适。木村様是客户，不能用自谦语描述客户动作 |
| おいでになったら | `行く/来る/いる` 的尊敬语 | 正解。描述客户“来” |
| おありだったら | `ある` 的尊敬语形式，但本句不表示“有” | 不合适。不能表示“来了” |
| 伺ったら | `行く/聞く/訪ねる` 的自谦语 | 不合适。也是说自己或己方动作，不用于客户 |

#### 高频考点

- `おいでになる`: `行く`、`来る`、`いる` 的尊敬语。
- `参る`、`伺う`: 自谦语，主要用于自己或己方。

#### 下次怎么判断

- 先看动作是谁做：来公司的是 `木村様`，是客户。
- 客户动作要抬高，用尊敬语 `おいでになる`。

#### 例句

- 先生がおいでになったら、こちらへご案内します。

### 7. 問題11

#### 原题完整记录（不要加工）

- 题干: 近所の図書館によく行くが、人気の本が貸し出し中で読めないことが多いので、もっと数を増やして、たくさんの人が読める（　）。

#### 选项

1. ようにしてほしい
2. ようにすることができる
3. ようになろうとしている
4. ようになりたい

#### 你的答案 / 正解

- 你的答案: 3. ようになろうとしている
- 正解: 1. ようにしてほしい

#### 中文翻译

- 我常去附近的图书馆，但热门书经常被借出读不到，所以希望能增加数量，让更多人可以读到。

#### 整句翻译

> もっと数を増やして、たくさんの人が読めるようにしてほしい。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| もっと数を増やして | 增加更多数量 | 希望对方采取的措施 |
| たくさんの人が読める | 很多人能读到 | 目标状态 |
| ようにしてほしい | 希望做到…… | 请求/希望对方调整状态 |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| ようにしてほしい | 希望对方设法做到某状态 | 正解。主语隐含为图书馆，希望图书馆增加书 |
| ようにすることができる | 能够设法做到…… | 不合适。句子不是说“我能做到” |
| ようになろうとしている | 正要变得能够…… | 不合适。主语通常是人或事物自然变化，不接这个请求语境 |
| ようになりたい | 想变得能够…… | 不合适。主语应是一人称“我”，但读书机会不是“我变得能够” |

#### 高频考点

- `V可能形 + ようにしてほしい`: 希望对方创造条件，让某事能实现。

#### 下次怎么判断

- 看到 `もっと数を増やして`，说明希望图书馆做某个调整。
- 后面要表达“让更多人能读到”，选 `ようにしてほしい`。

#### 例句

- 字を大きくして、後ろの人にも見えるようにしてほしい。

### 8. 問題12

#### 原题完整记录（不要加工）

- 题干: この国で、卵、牛乳（　）3番目に多い食物アレルギーは、小麦アレルギーだ。

#### 选项

1. に代わって
2. に沿って
3. についで
4. にしたがって

#### 你的答案 / 正解

- 你的答案: 1. に代わって
- 正解: 3. についで

#### 中文翻译

- 在这个国家，继鸡蛋、牛奶之后，第三多的食物过敏是小麦过敏。

#### 整句翻译

> 卵、牛乳についで3番目に多い食物アレルギーは、小麦アレルギーだ。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| この国で | 在这个国家 | 范围 |
| 卵、牛乳についで | 继鸡蛋、牛奶之后 | 排名顺序 |
| 3番目に多い | 第三多 | 排名表达 |
| 食物アレルギーは、小麦アレルギーだ | 食物过敏是小麦过敏 | 说明对象 |

#### 选项用法辨析

| 选项 | 用法 | 本题判断 |
|---|---|---|
| に代わって | 代替…… | 不合适。小麦不是代替鸡蛋、牛奶 |
| に沿って | 沿着……、按照…… | 不合适。没有路线、方针、计划 |
| についで | 继……之后，次于…… | 正解。和 `3番目`、排名语境搭配 |
| にしたがって | 随着……、按照…… | 不合适。不是变化随某条件推进 |

#### 高频考点

- `N + についで`: 继……之后，排名上接在某项之后。

#### 下次怎么判断

- 看到 `3番目`、`2番目`、`多い`、`少ない` 等排名信号，优先想 `についで`。

#### 例句

- この町では、バスについで自転車を利用する人が多い。

## 迷你复习题

### 問題

1. お客様に理由を聞く時: 理由を（　）よろしいでしょうか。
2. 漫画だけじゃない。小説を読むこと（　）ある。
3. 初めて（　）、なかなか上手だった。
4. そんな低い確率では、当たり（　）ない。
5. 結果がまだ出ていないので、判断し（　）。
6. 木村様が（　）なったら、応接室へ案内してください。
7. もっと本を増やして、多くの人が読める（　）ほしい。
8. 卵、牛乳（　）3番目に多い。

### 答え

1. お聞きしても
2. だって
3. にしては
4. っこ
5. かねる
6. おいでに
7. ようにして
8. についで

## 下次避免方法

- 敬语题先判断“动作是谁做”：自己做用自谦语，对方/客户做用尊敬语。
- 副词题不要只看中文大意，要看后面能不能直接修饰评价：`なかなか上手だ`。
- 固定句型题先找信号词：`まだ結果が出ていない` → `判断しかねる`，`3番目` → `についで`。
- 口语强否定看到“概率很低、不可能”，优先想 `Vます形 + っこない`。
