### 1. て以来

#### 原题完整记录（不要加工）

- 题干: X社の健康食品はテレビ番組で紹介（　）以来、とても売れている。

#### 选项

1. されて
2. される
3. されている
4. された

#### 你的答案 / 正解

- 你的答案: 4. された
- 正解: 1. されて

#### 中文翻译

- X公司的健康食品自从在电视节目中被介绍之后，就卖得非常好。

#### 整句翻译

> X社の健康食品はテレビ番組で紹介されて以来、とても売れている。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| テレビ番組で紹介されて以来 | 自从在电视节目中被介绍以来 | `Vて以来` 是固定接续 |
| とても売れている | 卖得很好 | `売れている` 表示持续状态 |

#### 为什么这样选

- `以来` 前面接 `Vて` 形，表示“自从……以后一直……”。被动动词是 `紹介される`，て形是 `紹介されて`。

#### 错因

- 把中文“被介绍了以后”的过去感直接套成 `された`。考试要先看接续，`以来` 的信号优先于中文时态。

#### 高频考点

- `Vて以来、ずっと/とても/今も...`。

#### 例句

- あのアニメを見て以来、日本語の勉強が楽しくなった。

### 2. まさか

#### 原题完整记录（不要加工）

- 题干: （テレビ番組で）司会「森もりさん、第五回X文学賞受賞おめでとうございます。今のお気持ちはいかがですか。」森もり「ありがとうございます。（　）受賞できるとは思わなかったので、すごくうれしいです。」

#### 选项

1. たとえ
2. まさか
3. せめて
4. かりに

#### 你的答案 / 正解

- 你的答案: 4. かりに
- 正解: 2. まさか

#### 中文翻译

- 主持人: 森先生/女士，恭喜您获得第五届X文学奖。现在心情如何？森: 谢谢。我没想到竟然能获奖，所以非常高兴。

#### 整句翻译

> まさか受賞できるとは思わなかったので、すごくうれしいです。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| まさか...とは思わなかった | 没想到竟然…… | 惊讶、出乎意料 |
| 受賞できる | 能获奖 | `受賞する` 的可能形 |

#### 为什么这样选

- `まさか...とは思わなかった` 是高频搭配，表示“完全没想到竟然……”。这里不是假设。

#### 错因

- `かりに` 是“假设”，常和 `ても/とすると` 连用。这里后面是 `とは思わなかった`，应想到惊讶表达。

#### 高频考点

- `まさかN2に合格できるとは思わなかった。`

#### 例句

- まさかこのゲームの大会で優勝できるとは思わなかった。

### 3. ざるを得ない

#### 原题完整记录（不要加工）

- 题干: わが国は、石油や石炭などのエネルギー資源がほとんどないため、多くを海外からの輸入に（　）。

#### 选项

1. 頼らざるを得ない
2. 頼るわけにはいかない
3. 頼らないに違いない
4. 頼ることにほかならない

#### 你的答案 / 正解

- 你的答案: 4. 頼ることにほかならない
- 正解: 1. 頼らざるを得ない

#### 中文翻译

- 我国几乎没有石油、煤炭等能源资源，因此不得不大量依赖从海外进口。

#### 整句翻译

> わが国は、石油や石炭などのエネルギー資源がほとんどないため、多くを海外からの輸入に頼らざるを得ない。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 資源がほとんどないため | 因为资源几乎没有 | 原因 |
| 輸入に頼る | 依赖进口 | `Nに頼る` |
| 頼らざるを得ない | 不得不依赖 | 没有其他选择 |

#### 为什么这样选

- 前面说资源很少，所以结论是“不得不依赖进口”。`Vない形去ない + ざるを得ない` 表示“不做不行”。

#### 错因

- `ことにほかならない` 表示“正是……”，用于定义或强调本质，不适合“不得不”的因果。

#### 高频考点

- `する` 的形式是 `せざるを得ない`，其他动词用ない形词干。

#### 例句

- 締め切りが明日なので、今夜は勉強せざるを得ない。

### 4. Vます形 + かける

#### 原题完整记录（不要加工）

- 题干: 先週末は、（　）かけだった3冊の本をすべて最後まで読んだ。

#### 选项

1. 読む
2. 読み
3. 読んで
4. 読んだ

#### 你的答案 / 正解

- 你的答案: 2. 読み
- 正解: 2. 読み

#### 中文翻译

- 上周末，我把读到一半的三本书全都读到了最后。

#### 整句翻译

> 先週末は、読みかけだった3冊の本をすべて最後まで読んだ。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 読みかけだった | 读到一半的 | `ます形 + かけ` |
| 3冊の本 | 三本书 | 数量词 |
| 最後まで読んだ | 读到最后 | 完成动作 |

#### 为什么这样选

- `Vます形 + かけ` 表示“做到一半、刚开始做”。`読む` 的ます形去ます是 `読み`。

#### 错因

- 这张截图显示你的答案和正解一致。仍建议保留，因为它是高频接续点。

#### 高频考点

- `食べかけ`、`書きかけ`、`読みかけ`。

#### 例句

- 読みかけのライトノベルを電車に忘れてしまった。

### 5. まず

#### 原题完整记录（不要加工）

- 题干: この作業はかなり大変なので、一日で終わらせるのは（　）無理だろう。

#### 选项

1. つい
2. まず
3. たとえ
4. 今に

#### 你的答案 / 正解

- 你的答案: 4. 今に
- 正解: 2. まず

#### 中文翻译

- 这项工作相当辛苦，所以一天内完成恐怕基本不可能。

#### 整句翻译

> この作業はかなり大変なので、一日で終わらせるのはまず無理だろう。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| かなり大変なので | 因为相当辛苦 | 原因 |
| 一日で終わらせる | 一天内完成 | 使役形 |
| まず無理だろう | 大概基本不可能 | 判断副词 |

#### 为什么这样选

- `まず無理だろう` 表示“十有八九不可能、基本不可能”。这是判断，不是时间上的“将来”。

#### 错因

- `今に` 表示“不久、迟早”，常带期待或预感，如 `今に分かる`。后面接 `無理だろう` 不自然。

#### 高频考点

- `まず` 除了“首先”，也可表示“大概、基本上”，常和否定判断搭配。

#### 例句

- 今日中にこの分量を全部覚えるのはまず無理だ。

### 6. とのことです

#### 原题完整记录（不要加工）

- 题干: （会社で）山下「田中さん、先ほどABC建設の木村様からお電話がありました。至急連絡がほしい（　）。」田中「はい、わかりました。」

#### 选项

1. までです
2. とします
3. とのことです
4. ことになります

#### 你的答案 / 正解

- 你的答案: 2. とします
- 正解: 3. とのことです

#### 中文翻译

- 山下: 田中先生/女士，刚才ABC建设的木村先生/女士来电话了。说是希望您尽快联系。田中: 好的，我知道了。

#### 整句翻译

> 至急連絡がほしいとのことです。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 至急連絡がほしい | 希望尽快联系 | 对方的要求 |
| とのことです | 据说、对方说 | 转述信息 |

#### 为什么这样选

- 职场转述对方留言时，用 `とのことです` 很自然，语气礼貌。

#### 错因

- `とします` 表示“假定为/决定为”，不用于转达别人留言。

#### 高频考点

- `N/普通形 + とのことです`，正式场景常见。

#### 例句

- 先生は会議で少し遅れるとのことです。

### 7. しないことには

#### 原题完整记录（不要加工）

- 题干: （就職説明会で）「就職活動とは、企業に応募することです。この企業で働きたいと思っていても、応募（　）、何も進みません。まずは応募しましょう。」

#### 选项

1. してみるより
2. できるといいし
3. しないことには
4. するのではなく

#### 你的答案 / 正解

- 你的答案: 4. するのではなく
- 正解: 3. しないことには

#### 中文翻译

- “所谓求职活动，就是向企业投递申请。即使你想着想在这家公司工作，如果不申请，什么都不会进展。首先申请吧。”

#### 整句翻译

> 応募しないことには、何も進みません。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| 応募しないことには | 如果不申请 | 必要条件 |
| 何も進みません | 什么都不会推进 | 后项多为否定 |

#### 为什么这样选

- `Vないことには、...ない` 表示“如果不……就不能……”。后面 `何も進みません` 是强烈信号。

#### 错因

- `するのではなく` 是“不是做A，而是做B”，需要后面有对比内容；本句没有“而是”结构。

#### 高频考点

- 后项常是否定或困难判断: `見てみないことには分からない`。

#### 例句

- 実際に問題を解かないことには、弱点は分からない。

### 8. ぐらいなら

#### 原题完整记录（不要加工）

- 题干: 私は歯医者が苦手だ。歯の痛みがひどい時には行くが、少し（　）我慢してしまう。

#### 选项

1. 痛くなる前に
2. 痛そうなときは
3. 痛いぐらいなら
4. 痛くないのだから

#### 你的答案 / 正解

- 你的答案: 4. 痛くないのだから
- 正解: 3. 痛いぐらいなら

#### 中文翻译

- 我不喜欢看牙医。牙痛得厉害时会去，但如果只是有点痛，就会忍着。

#### 整句翻译

> 歯の痛みがひどい時には行くが、少し痛いぐらいなら我慢してしまう。

#### 整句拆解

| 片段 | 意思 | 说明 |
|---|---|---|
| ひどい時には行く | 严重时会去 | 对比前项 |
| 少し痛いぐらいなら | 如果只是有点痛的话 | 程度较轻的假设 |
| 我慢してしまう | 就忍了 | 不理想但会做 |

#### 为什么这样选

- `ぐらいなら` 表示“如果只是这种程度的话”。和 `少し` 搭配，表示“只是有点痛就忍着”。

#### 错因

- `痛くないのだから` 是“既然不痛”，和前面的 `少し`、后面的 `我慢する` 逻辑不合。

#### 高频考点

- `少し/この程度 + ぐらいなら`。

#### 例句

- 少し眠いぐらいなら、復習してから寝る。

## 下次避免方法

- 先看空格后面的固定搭配: `以来`、`とは思わなかった`、`無理だろう`、`何も...ない`。
- 看到中文像“以后、竟然、不得不”时，不要先翻译，先确认日语接续。
