# 错题本索引

标签: `#错题` `#索引` `#jlpt-n2`

## 命名规则

错题批次按年月归档：

> `mistakes/YYYY/MM/YYYY-MM-DD-n2-题型-题量-items.md`

例：

> `mistakes/2026/04/2026-04-28-n2-bunpou-goi-08-items.md`

这样以后可以按“日期回看当时错题”，也可以通过文件名看出内容范围。

## 自动化入库

新截图放到项目根目录后，可以先运行脚本：

```bash
python scripts/new_mistake_batch.py --date 2026-04-29 --type bunpou-goi --count 6
```

脚本会自动归档截图、生成批次模板，并输出索引更新草稿。详细说明见 [../docs/automation.md](../docs/automation.md)。

## 如何使用这个错题本复习

### 1. 快速复盘：15 分钟

适合碎片时间。

1. 打开下面的“批次列表”。
2. 选择最近一次错题。
3. 只看「错题总览」。
4. 对每一题问自己一句：我当时为什么会选错？
5. 做文末的迷你复习题。

目标不是全部重学，而是唤醒记忆。

### 2. 专项突破：30 到 45 分钟

适合认真学习。

1. 从“按题型复习”进入，例如「文法」或「語彙」。
2. 找一个反复出错的主题。
3. 进入对应的主题笔记，例如 `もっとも・しかも・かりに・たとえ`。
4. 按「意思 → 接续 → 语感 → 相似语法比较 → 例句 → 易错点」学习。
5. 回到错题批次，重新做原题。
6. 用自己的话写一句总结：下次看到什么信号，我要选什么。

例：

> 看到 `かりに...とすると`，是在临时假设后做推论，不要选 `たとえ`。

### 3. 考前复习：60 分钟

适合集中查漏补缺。

1. 先看“按题型复习”里的文法索引。
2. 只复习自己错过的主题笔记。
3. 每个主题只抓三件事：接续、语感、易错对比。
4. 再看語彙索引，重点背搭配。
5. 最后回到批次列表，快速扫一遍所有错题总览。

考前不要重读所有解释，优先看表格、例句和易错点。

### 4. 新错题加入后的复习动作

每次新错题整理好后，建议当天做一次：

1. 看错题总览。
2. 看我整理出的主题笔记。
3. 做迷你复习题。
4. 第二天只看错题总览，再做一次迷你复习题。
5. 一周后从题型索引回顾同类题。

这样可以把“错过一次”变成“以后少错一类”。

## 按题型复习

错题批次仍按日期保存一份，题型目录只做索引，避免同一题复制到多个地方后不同步。

| 题型 | 入口 | 用途 |
|---|---|---|
| 文法 | [by-type/bunpou](by-type/bunpou/README.md) | 文法填空、句型辨析、接续词、助词 |
| 文の組み立て | [by-type/bunpou-kumitate](by-type/bunpou-kumitate/README.md) | 排序题、修饰关系、固定结构、句子骨架 |
| 語彙 | [by-type/vocabulary](by-type/vocabulary/README.md) | 词语用法、搭配、近义词辨析 |
| 漢字 | [by-type/kanji](by-type/kanji/README.md) | 漢字读音、字形、熟词、易混项 |
| 読解 | [by-type/reading](by-type/reading/README.md) | 短文、中篇、长篇、信息检索 |
| 聴解 | [by-type/listening](by-type/listening/README.md) | 听力表达、场景判断、即时反应 |

## 复习顺序

1. 想复盘当天状态：从下面的“批次列表”进入。
2. 想专项突破：从“按题型复习”进入。
3. 进入批次后，先看自己当时错在哪里。
4. 再看批次里的“复习入口”，跳到语法、词汇、阅读等主题笔记。
5. 最后做批次末尾的迷你复习题。
