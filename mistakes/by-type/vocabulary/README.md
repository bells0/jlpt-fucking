## 常见错误模式

| 模式 | 判断提醒 |
|---|---|
| 中文意思接近就选 | 看宾语：人、申请、资料、技术 |
| 忽略固定搭配 | `留学生を受け入れる`、`申し込みを受け付ける` |
| 混淆抽象和具体 | `現実を受け入れる`，但 `パンフレットを受け取る` |
| 只按中文意思套词 | `和やかな味` 不自然，固定看 `和やかな雰囲気` |
