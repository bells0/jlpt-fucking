## 常见错误模式

| 模式 | 判断提醒 |
|---|---|
| 只按中文意思选 | 先判断前后逻辑：补充、追加、假设、逆接 |
| 忽略固定搭配 | `かりに...とすると`、`たとえ...ても` |
| 忽略动作时点 | “正要做”与“做着做着”完全不同 |
| 忽略助词 | `で` 可以表示媒介，决定句子结构 |
| 没还原句子骨架 | 文の組み立て题先找固定结构和修饰关系 |
| 敬语先看词不看主语 | 先判断动作是谁做：自己动作自谦，对方动作尊敬 |
