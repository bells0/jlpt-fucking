# 読解错题索引

标签: `#错题` `#読解` `#jlpt-n2`

## 复习目标

阅读错题要记录：

- 原题：题干、选项和文章依据要完整保留。
- 题型：内容理解、理由说明、指示词、主旨、信息检索。
- 错因：定位错、转折没看懂、选项偷换、时间不够。
- 原文依据：答案对应哪一句或哪一段。
- 下次策略：先看问题、划转折、抓指示词、排除绝对化选项。

## 阅读错因模板

| 错因 | 复盘问题 |
|---|---|
| 定位错误 | 我是在哪一句开始读偏的？ |
| 转折遗漏 | `しかし`、`ところが`、`ただ` 后面有没有真正读懂？ |
| 指示词没回指 | `これ`、`それ`、`その` 指的是什么？ |
| 选项偷换 | 选项有没有把“部分”说成“全部”？ |
| 时间压力 | 是文章没读懂，还是题目策略慢？ |
