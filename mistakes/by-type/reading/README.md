## 复习目标

阅读错题要记录：

- 原题：题干、选项和文章依据要完整保留。

- 错因：定位错、转折没看懂、选项偷换、时间不够。
- 原文依据：答案对应哪一句或哪一段。
- 下次策略：先看问题、划转折、抓指示词、排除绝对化选项。

## 阅读错因模板

| 错因 | 复盘问题 |
|---|---|
| 定位错误 | 我是在哪一句开始读偏的？ |
| 转折遗漏 | `しかし`、`ところが`、`ただ` 后面有没有真正读懂？ |
| 指示词没回指 | `これ`、`それ`、`その` 指的是什么？ |
| 选项偷换 | 选项有没有把“部分”说成“全部”？ |
| 时间压力 | 是文章没读懂，还是题目策略慢？ |

## 考前快速口诀

- 先看问题，再读文章。
- 理由题找 `なぜ`、`というのは`、`からだ`。
- 指代题往前 1-2 句找。
- 作者观点题盯 `しかし`、`つまり`、`大切なのは`、`必要なのは`。
- 太绝对的选项先怀疑：`必ず`、`全部`、`まったく`。
- 原文说“有时候”，选项说“一定”，基本错。
- 原文说“不只是 A”，选项说“A 不重要”，也错。

一句话：読解不是看懂大概，而是把选项里的对象、方向、目的、评价和原文逐项对齐。
