# 聴解错题索引

标签: `#错题` `#聴解` `#jlpt-n2`

## 复习目标

听力错题要记录：

- 原题：题干、选项和关键信息要完整保留。
- 场景：学校、公司、店铺、电话、通知。
- 错因：没听出转折、没抓最终决定、人物关系混乱、数字时间漏听。
- 关键表达：题目里真正决定答案的那一句。

## 听力错因模板

| 错因 | 复盘问题 |
|---|---|
| 最终决定没抓住 | 最后到底改成了什么？ |
| 转折没听出 | `でも`、`ただ`、`やっぱり` 后面有没有改答案？ |
| 人物关系混乱 | 谁要做什么？谁拜托谁？ |
| 数字漏听 | 时间、金额、数量有没有二次修正？ |
