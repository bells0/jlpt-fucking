## 复习目标

文の組み立て题不要只背完整句，要回到原题的排序形式重新做一次。

每道题复盘时必须确认：

- 原题的 `＿＿ ＿＿ ★ ＿＿` 形式。
- 全部选项 1・2・3・4。
- 你的答案和正解。
- 正确顺序和 ★答案。
- 完整句、翻译、固定结构和下次判断方法。

## 常见错误模式

| 模式 | 判断提醒 |
|---|---|
| 只看局部能不能接 | 局部能接不等于 ★ 位置正确，先还原整句骨架 |
| 没找固定结构 | `Nがあって初めて`、`Nのおかげだ` 这种结构要整体识别 |
| 修饰关系拆错 | 动词普通形后接名词时，前面常整体修饰后面的名词 |
| 没数星号位置 | 正确顺序确定后，再确认 ★ 是第几个空 |
