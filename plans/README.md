## 使用方法

1. 从下面的计划列表进入当前计划。
2. 每天在计划中勾选任务，并填写当天结果。
3. 未完成的内容写入「顺延任务」，不要直接删除。
4. 计划内容调整后，同步更新本索引中的说明和根目录的“最近更新”。
