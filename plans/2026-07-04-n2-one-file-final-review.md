### 語彙易混组

| 易混组 | 怎么分 |
|---|---|
| 実践 / 実験 / 実現 | `実践` 是把理论付诸行动；`実験` 是实验；`実現` 是实现。 |
| 敬う / 拝む / 尊ぶ | `敬う` 尊敬人；`拝む` 拜、祈祷；`尊ぶ` 尊重价值。 |
| 徐々に / やっと | `徐々に` 强调逐渐变化；`やっと` 强调终于达成。 |
| 剥げる / こぼれる | `剥げる` 是表面脱落；`こぼれる` 是液体等洒出。 |
| 薄める / 下げる / 小さくする | 味道、浓度 `薄める`；温度、水平 `下げる`；音量 `小さくする`。 |
| 鮮明 / はっきり | `鮮明` 偏记忆、画面、印象；`はっきり` 用法更广。 |
| 絡まる / 挟まる | `絡まる` 缠绕；`挟まる` 夹在中间。 |
| もてなす / おだてる | `もてなす` 招待；`おだてる` 奉承、哄。 |
| 溶け込む / 触れ合う | `溶け込む` 融入群体；`触れ合う` 接触交流。 |
| はきはき / はっきり | `はきはき` 说话回答清楚；`はっきり` 看得清楚、意思明确。 |

### 語彙小测

1. `すぐに実践できる` 中 `実践` 的读音是？
2. `安全な場所に＿＿する`，表示避难。
3. `パソコン教室の講座を＿＿する`，表示参加课程。
4. `スープがしょっぱいので、水を加えて味を＿＿。`
5. `あのときの出来事は今でも＿＿に覚えている。`
6. 状況を（しょうさい）に説明する。漢字は？
7. 子どもの `読書＿＿` が進んでいる。
8. おいしい料理で客を＿＿。
9. 遠くの山が＿＿見える。`はきはき` / `はっきり`
10. 転校生がクラスにすっかり＿＿。

**答案**：1. `じっせん`　2. `避難`　3. `受講`　4. `薄める`　5. `鮮明`　6. `詳細`　7. `離れ`　8. `もてなす`　9. `はっきり`　10. `溶け込む`

> [!tip] 語彙考场口诀
> 不只看中文，看对象。课程是 `受講`，语气是 `口調`，味道才可以 `薄める`，记忆和画面才容易 `鮮明`。

## 2. 文法

### 最近最该稳住的句型

| 句型 / 表达 | 意思 | 判断信号 | 例句 |
|---|---|---|---|
| `NさえVない` | 连……都不 | 极端小事也做不到 | 水に顔をつけることさえできなかった。 |
| `まず無理だろう` | 恐怕不可能 | 对实现可能性的判断 | 一日で終わらせるのはまず無理だろう。 |
| `〜てからでないと〜ない` | 不先……就不能…… | 后项是否定 | 返してからでないと借りられない。 |
| `〜わけではない` | 并不是…… | 部分否定 | 完全に治ったわけではない。 |
| `Vます形 + がたい` | 难以…… | 心理上难忘、难接受 | 忘れがたい経験。 |
| `もう少しで〜ところだった` | 差点就…… | 险些发生 | もう少しで洗濯するところだった。 |
| `〜てしまうことがある` | 有时不由得…… | 不受控制、不如预期 | 自分のほうが寝てしまうことがある。 |
| `するだけしてみる` | 能试的先试试看 | 建议挑战 | チャレンジするだけしてみたら？ |
| `〜を気にするあまり` | 过于在意……以至于 | 后项多消极 | 人目を気にするあまり言えない。 |
| `Nも必要` | N 也必要 | 前面已有其他必要条件 | 知識も体力も必要だ。 |
| `Vてよかった` | 做了……真好 | 对实际体验的评价 | やってみて本当に良かった。 |
| `AやBといったC` | A、B 这类 C | 具体例子列举类别 | きゅうりやトマトといった夏の野菜。 |
| `〜のであれば` | 如果是……的话 | 根据已发生事实作条件判断 | 海水が入ったのであれば、修理は難しい。 |
| `〜ておく` | 提前做准备 | 避免之后慌张 | 少しずつやっておこう。 |
| `〜までになる` | 达到……程度 | 数量变化、增长 | 200を超えるまでになった。 |
| `〜が欠かせない` | 不可或缺 | `〜には` 后接必要条件 | チーム作業には連絡が欠かせない。 |
| `〜ばよかった` | 当时要是……就好了 | 已发生后的后悔 | 電車で行けばよかった。 |
| `伺ってもよろしいでしょうか` | 可以请问……吗 | 电话、接待、询问对方信息 | お名前を伺ってもよろしいでしょうか。 |
| `〜からわかるように` | 如从……可知 | 排序题固定结构 | 漢字からわかるように春の魚だ。 |
| `〜ようになる` | 变得…… | 认识、习惯、能力变化 | 強く感じるようになりました。 |

### 文法易混点

| 易混点 | 该选哪个 | 判断法 |
|---|---|---|
| `さえ` / `ばかり` | 连小事都做不到选 `さえ` | `ばかり` 是“光是、净是”。 |
| `たとえ` / `まず` | 判断“不可能”选 `まず` | `たとえ` 后常接 `〜ても`。 |
| `てからでないと` / `てはじめて` | 后项否定选 `てからでないと` | `はじめて` 强调做了 A 才第一次 B。 |
| `わけではない` / `にすぎない` | 部分否定选 `わけではない` | `にすぎない` 是“只不过”。 |
| `やってみて` / `やってみたら` | 实际尝试后的评价选 `やってみて` | `たら` 是假设条件。 |
| `どんなに` / `どれほど` | 问“多少人”选 `どれほど` | `どんなに` 常接让步或程度副词句。 |
| `に関する` / `といった` | 列举例子选 `といった` | `AやB` 后常是列举。 |
| `伝える` / `伺う` | 问姓名选 `伺う` | 自己问对方信息，用自谦语。 |
| `ばよかった` / `はずだった` | 后悔选 `ばよかった` | 已经做错选择，再说“当时要是……”。 |

### 排序题只记这个方法

1. 先找谓语。
2. 再找被修饰名词。
3. 长定语先合成一块。
4. 固定结构不要拆：`ことからわかるように`、`するだけしてみる`、`〜というN`。
5. 最后再数 `★` 的位置。

### 文法小测

1. この作業を一日で終わらせるのは（　）無理だろう。
2. 借りている本を全部返して（　）、ほかの本は借りられない。
3. もう少しで領収書を入れたまま洗濯する（　）。
4. 体力（　）必要で、農業は本当に大変だ。
5. チャレンジする（　）してみたら？
6. きゅうりやトマト＿＿夏の野菜。
7. チーム作業には十分なコミュニケーション＿＿。
8. やはり電車で行け＿＿。
9. お名前を＿＿てもよろしいでしょうか。
10. 漢字で「鰆」と書くことから＿＿ように。

**答案**：1. `まず`　2. `からでないと`　3. `ところだった`　4. `も`　5. `だけ`　6. `といった`　7. `が欠かせない`　8. `ばよかった`　9. `伺っ`　10. `わかる`

> [!tip] 文法考场口诀
> 看到空格先问功能：条件、追加、部分否定、后悔、自然结果、敬语询问，还是前后文照应。不要先拿中文硬套。

## 3. 読解

### 最近阅读最容易丢分的模式

| 错因 | 典型表现 | 下次动作 |
|---|---|---|
| 只抓末句词面 | 看见 `世界が広がっている` 就选“越多越好” | 主旨题回到作者结论整体。 |
| 定位到结果而非原因 | 题问原因，却只看后面的结果 | 找 `必要がある`、`そのため` 前面的内容。 |
| 选项擅自追加评价 | 选项看似像原文，但多了好坏、目的、对象 | 删除选项里原文没有的词再判断。 |
| 指示词回指不精确 | `この行為`、`それ` 指代读错 | 回看前后 1 到 2 句。 |
| 方向读反 | `AをBとみなす` 的 A/B 反了 | 标出 A 和 B。 |
| 抓背景不抓评价 | 只看到猫不合群，漏掉 `しかし` 后的魅力 | 转折后单独画线。 |
| 转折后结论遗漏 | 忽略 `そうではなく` 后作者观点 | `しかし`、`そうではなく` 后优先看。 |
| 关键词误连 | 把关键词连到错误修饰对象 | 看关键词前后的修饰语。 |
| 两篇比较只看一半 | A 半句对，B 半句被偷换还选了 | A/B 分开核对，任一半错就排除。 |
| 常识补全 | 选项符合常识，但原文没说 | 原文没有的目的、效果不选。 |

### 読解题型策略

| 题型 | 先看哪里 | 答题动作 |
|---|---|---|
| 社内文書、公告 | 最后的要求句、命令句 | 找 `〜してください`、`必要があります`。 |
| 主旨题 | 作者结论句整体 | 不要只拿最后一句的一个词。 |
| 下划线解释 | 下划线前后两句 | 代词、原因、评价都要回指。 |
| 原因题 | `ため`、`から`、`必要がある` 前后 | 不要把结果当原因。 |
| 内容一致 | 选项逐项核对 | 对象、方向、目的、评价一个个看。 |
| 两篇比较 | A 文、B 文分别写依据 | 选项拆成 A 半句和 B 半句。 |

### 読解小测

1. 社内文書题问 `社員が求められていること`，优先看哪类句子？
2. `そうではなく、作品の解釈は読者それぞれでいい。` 对应“作者意图”相关选项时，应选“追求作者意图”还是“不受作者意图束缚”？
3. A/B 比较题里，选项 A 半句正确、B 半句被偷换，能不能选？
4. `より一般的で全体的な観点から問い直す` 的核心是“专家视点”还是“更一般整体的视点”？
5. 作者最想说的是“人生选择越多越好”还是“生き方は一つではない”？
6. 制定计划时不能以什么状态为基准？
7. 摄影相关题的关键词是“观众感到魅力”还是“私はこう見た”？
8. `この行為` 这类指示词题，应该看哪里？

**答案**：
1. 最后的要求句、命令句，例如 `〜してください`。
2. 不受作者意图束缚。
3. 不能选。A/B 任一半不符合原文就排除。
4. 更一般整体的视点。
5. `生き方は一つではない`。
6. `脳が最も快調にはたらいているとき`。
7. `私はこう見た`。
8. 下划线前后 1 到 2 句，先确定它指代什么。

> [!tip] 読解考场口诀
> 不是看懂大概就选。选项里的对象、方向、目的、评价，都要能指回原文。

## 4. 聴解

### 今天只练这个流程

1. 从软件错题本挑最近最不稳的 3 到 5 题。
2. 每题先盲听一遍，不看原文。
3. 标出没听懂的句子或关键词。
4. 看原文确认意思。
5. 带着中文意思重听，直到连续理解。

### 聴解考场抓点

| 问题类型 | 要抓什么 |
|---|---|
| 下一步动作 | 最后的决定、请求、変更 |
| 理由题 | `実は`、`というのは`、`だから` 后面 |
| 人物关系 | 谁请求谁、谁拒绝谁、谁让步 |
| 时间地点 | 日期、締切、集合場所、変更后的信息 |
| 图表题 | 先确认条件，再排除不符合项 |
| 即时应答 | 语气是否自然，是否接得上前一句 |

### 聴解提醒

- 没听懂一小段，不要停在那一句里慌。
- 听到 `でも`、`ただ`、`それより`，要更新判断。
- 问 `何をするか` 时，优先听最后的决定或请求。
- 听力不是全文翻译，重点是人物、请求、理由、下一步动作。

## 5. 最后两天蒙分策略

> [!warning] 使用原则
> 蒙分不是乱猜，是在不会的时候先排除错误答案。先做会做的；不会的题，至少排掉两个，再二选一。

### 1. 单词读音题

- 先看是不是熟词。熟词别乱改第一感觉，很多错是想太多。
- 两个字以上的漢字词，大概率先按音读想：`計画（けいかく）`、`経験（けいけん）`。
- 带假名尾巴的动词、形容词，大概率看训读：`読む（よむ）`、`新しい（あたらしい）`。
- 看到促音 `っ`、长音 `う` 要特别小心。N1、N2 很爱考少背一个音。
- 完全不会时，先排除看起来太离谱的读音，再选最像常见音读组合的：`しょう`、`じょう`、`こう`、`けい`、`かん`、`せい`。

### 2. 汉字写法题

- 先看句子意思，不要只看读音。同音词是坑。
- 例：`かんしん`  
  `関心` = 感兴趣。  
  `感心` = 佩服。
- 完全不会时，找和句子意思最贴的汉字部件。
- 和心情有关，多看 `心`。
- 和水有关，多看 `氵`。
- 和动作、手有关，多看 `扌`。
- 和钱有关，多看 `貝`。
- 别选那个只是读音像、但意思完全不搭的。

### 3. 词义题

- 先判断句子整体是好意思、坏意思，还是普通描述。
- 看前后有没有转折词。`でも`、`しかし`、`ところが` 后面经常才是重点。
- 遇到陌生词，看它修饰谁。
- 修饰人，多半是性格、态度。
- 修饰事，多半是状态、程度。
- 修饰动作，多半是方式。
- 蒙的时候，四个选项里如果有一个意思太绝对，比如 `必ず`、`全部`、`まったく`、`只能`，先谨慎。能力考更喜欢细微表达，不太喜欢特别死的说法。

### 4. 近义词替换题

- 不要只看中文意思，要看搭配。
- 例：`影響を受ける` 不是随便一个“影响”都能替。
- 例：`不満を抱く` 不是所有“有”都能换。
- 先看原句这个词前后接了什么助词：`を`、`に`、`が`、`と`、`で`。
- 判断选项能不能和原句自然接在一起。
- 蒙的时候，两个选项意思都像，优先选和原句语气一样的。原句正式，就别选太口语的；原句普通，就别选太书面的大词。

### 5. 词语用法题

- 这是单词题里最容易丢分的。别只看这个词是什么意思，一定看它平时跟谁一起用。
- 必背搭配：
  - `疑問を抱く`
  - `責任を負う`
  - `期待に応える`
  - `希望がかなう`
  - `努力が実る`
- 如果四个句子里有一个搭配特别顺，基本就是它。
- 蒙的时候，先排除中文直译很顺、但日语不自然的。能力考很爱用这种骗中国学生。

### 6. 语法题

- 先看接续：前面是名词、动词原形、`た形`、`ない形`、`て形`。接续不对直接划掉。
- 别急着翻译。很多题一翻译就被中文带跑。
- 再看句尾：命令、推测、感叹、后悔、义务、禁止、让步。
- 句尾语气能帮你排一半。
- 蒙的时候，先选最符合前后关系的：原因、转折、让步、条件、目的。
- 不要选你背得最熟的那个，熟不代表对。

### 7. 排序题

- 先找固定搭配：
  - `ことができる`
  - `わけではない`
  - `に違いない`
  - `ざるを得ない`
  - `ないことはない`
- 然后找谁修饰谁。长句子里，名词前面一定有修饰它的东西。
- 最后再看助词。`は`、`が`、`を`、`に`、`で`、`と` 很多时候能决定顺序。
- 蒙的时候，先把明显连在一起的两块拼出来，不要四个空一起想。

### 8. 阅读题

- 先看问题，再读文章。别上来从头精读。
- 题目问理由，就找 `なぜ`、`というのは`、`からだ`。
- 题目问指代，就往前一句、两句找。
- 题目问作者观点，就盯着 `しかし`、`つまり`、`大切なのは`、`必要なのは`。
- 阅读里最重要的一句话通常在转折后面。前面铺垫再长，后面一个 `しかし` 就能翻盘。
- 蒙的时候，太绝对的选项先怀疑。
- 和原文换了程度的选项也要小心：原文说“有时候”，选项说“一定”，基本错。
- 原文说“不只是 A”，选项说“A 不重要”，也错。

### 9. 听力题

- 不要试图每个词都听懂，先抓任务：谁要做什么、什么时候做、先做什么、最后决定是什么。
- 听到 `でも`、`いや`、`ただ`、`それより`，后面重点来了。前面一堆可能都是干扰。
- 即时应答题别翻译太慢，听语气就行。
- 道歉接：`いいえ、大丈夫です`。
- 感谢接：`どういたしまして`。
- 邀请接：`いいですね` / `すみません、ちょっと`。
- 请求接：`はい、わかりました`。
- 蒙的时候，选最自然、最短、最像日本人会回的，不是选中文意思最完整的。

### 10. 考场时间技巧

- 单词、语法别恋战。不会就标记，先走。
- 阅读最怕前面小题耗太久。长阅读先看题目，带着问题找答案。
- 听力错过就错过，千万别回想上一题。你一回想，下一题也没了。
- 能力考不是考你会不会每个词，是考你能不能在有限时间里排掉错误答案。
- 不会的题也别空着。先排两个，剩下二选一，分就来了。

## 6. 明天考场最终提醒

### 文字・語彙

- 漢字读音题不要拆字乱猜，先想整词：`実践`、`詳細`、`農薬`。
- 表记题用固定搭配回忆：`安全な場所に避難する`、`志望理由`、`桜が散る`。
- 近义题先看对象：`客をもてなす`、`クラスに溶け込む`、`味を薄める`。
- 完整句用法题不要只看词义，要看搭配自然不自然。

### 文法

- 空格题先判断句子功能，再代入选项。
- 排序题先找骨架：谓语、被修饰名词、长定语。
- 敬语题先判断动作主语：谁做动作，动作朝向谁。
- 文章语法题必须看前后文，尤其是指示词、转折、追加。

### 読解

- 先看题干，带着问题读。
- 下划线题看前后两句，不只看下划线词。
- 选项出现目的、评价、绝对化表达时，回原文确认。
- 两篇比较题把 A/B 分开核对，不要凭印象合并。

### 聴解

- 第一遍抓场景和人物关系。
- 题目问 `何をするか` 时，优先听最后的决定或请求。
- 听到转折后更新判断：`でも`、`ただ`、`それより`。
- 没听懂一小段，马上抓下一句能确定的信息。

## 7. 睡前最后 10 分钟

只问自己这 5 个问题：

| 项目 | 自问 |
|---|---|
| 語彙 | 我有没有看对象和固定搭配？ |
| 文法 | 我有没有先判断句子功能？ |
| 読解 | 我有没有把选项逐项指回原文？ |
| 聴解 | 我有没有抓人物、请求和下一步动作？ |
| 心态 | 我有没有把不会的题及时放过？ |

最后记这一句：

`焦らず、読めるところから確実に取る。`

明天的目标不是满分，是稳定。不会的题可以放过，会做的题要拿稳。
