## 学习执行方法

### 1. 真题：只用软件完成

- 使用软件：**烧饼日语、mojitest**。
- 本轮冲刺不使用纸质试卷。
- 23年07月、23年12月真题可以直接在软件中完成；从 24年07月真题开始严格按照考试时间限时作答。
- 单词、语法部分优先使用软件题库刷题，让软件自动生成错题记录。
- 做错的题，以及虽然做对但还想二刷的题，都要加入错题本或收藏夹。
- 后期直接通过软件的错题本和收藏夹二刷，用刷题的方式复习单词、语法。

### 2. 错题本：以软件错题本和收藏夹为主

- 使用烧饼日语、mojitest 自动生成的错题本，不另外抄写完整题目。
- 不认识的单词、不熟悉的语法和想再次练习的题，立即加入收藏夹。
- 整理错题时至少确认三件事：**正确答案、自己错选的原因、下次如何判断**。
- 复习时不要只看答案，要重新作答；再次做错的题继续保留在复习范围内。
- 软件中不方便补充的详细解析，再整理到本仓库的错题笔记。

### 3. 听力错题：盲听 → 看原文 → 带意思重听

> 目标是练习听懂，不做全文听写，也不把精听变成跟读训练。

1. **先盲听一遍**：不中途看原文，在脑中标记没有听到或没有听懂的句子。
2. **核对听力原文**：逐句阅读，用自己的中文确认每句话的意思。
3. **带着意思重听**：听到日语时，脑中要能及时反映出句子的中文意思。
4. **重复薄弱部分**：仍然听不懂就回看原文，再听一次。
5. **通过标准**：整篇连续听一遍，没有任何听不懂的地方，才算完成。

每道听力错题完成后检查：

- [ ] 已完成第一次盲听。
- [ ] 已标出没听懂的句子。
- [ ] 已逐句确认原文和意思。
- [ ] 已重听到整篇无障碍理解。

### 4. 阅读错题：分析选项，不做全文翻译

> 目标是快速检索答案和识别干扰项，不是把文章逐句翻译成中文。

1. 带着题干和选项回到文章中，快速定位相关内容。
2. 找出正确选项在文中的依据，确认它与前后两三句话的关系：因果、递进、转折、并列或举例。
3. 分析错误选项为什么不能选：它对应文中的什么位置？与上下文是什么关系？
4. 记录自己为什么会被错误选项误导，例如偷换对象、范围扩大、因果颠倒或只符合局部信息。
5. 最后用一句话写出选择正确答案的依据。

每道阅读错题完成后检查：

- [ ] 已定位正确选项的原文依据。
- [ ] 已说明正确选项与上下文的关系。
- [ ] 已说明错误选项的干扰方式。
- [ ] 已写出自己错选的具体原因。
