# JLPT N2 个人知识库

这个仓库是为了通过 JLPT N2 而建立的个人日语学习知识库。

本项目的默认助手角色定义在 [[AGENTS|AGENTS.md]]：**JLPT N2 学习陪练与知识库编辑者**。

## 目标

- 讨论日语语法、词汇、阅读、听力和考试策略。
- 用日本动画、游戏、漫画、轻小说和文化兴趣作为学习材料。
- 纠正错误，并把错误整理成可复习资料。
- 积累适合 JLPT N2 复习的マークダウン笔记。
- 说明要实用、面向考试、方便回顾。

## 索引维护规则

以后新增或更新内容时，必须同时完成：

1. 把文件加入所在分类的 `README.md` 索引。
2. 如果是新的学习主题、错题批次或计划，在根目录“最近更新”登记日期、更新内容和入口。
3. 如果笔记来自错题，要让错题批次、题型索引和主题笔记互相链接。
4. 交付前检查新文件能否从本页出发，在两次点击以内找到。

## 怎么开始复习

平时复习从这里开始：

> [[mistakes/README|mistakes/README.md]]

如果今天只想快速复盘，按这个顺序：

1. 进入 `mistakes/README.md`。
2. 选择“按题型复习”或“批次列表”。
3. 先看错题批次，确认自己当时错在哪里。
4. 再跳到相关语法或词汇主题笔记。
5. 最后做批次末尾的小练习。

如果不知道学什么，优先从「文法」开始；如果最近错的是排序题，就从「文の組み立て」入口重新做原题排序。

## 错题知识库流程

新增截图或错题时：

1. 把原始截图放到项目根目录。
2. 运行自动化脚本归档截图并生成批次模板。
3. 在生成的批次笔记里补全题目、正解、错因、语法点、例句和复习题。
4. 把批次笔记加入 `mistakes/by-type/` 下对应题型索引。
5. 可复用语法点整理到 `grammar/`。
6. 词汇、搭配、近义辨析整理到 `vocabulary/`。
7. 批次笔记和相关主题笔记互相链接。

整理错题时，必须先完整保留原题。题干和全部选项是基础，解析和总结只能放在原题记录之后。

常用命令：

```bash
python3 scripts/new_mistake_batch.py --date 2026-04-29 --type bunpou-goi --count 6
```

详细说明见 [[docs/automation|docs/automation.md]]。

手动规则仍然是：

1. 原始截图归档到 `mistakes/assets/YYYY-MM-DD/`。
2. 在 `mistakes/YYYY/MM/` 下建立当天错题批次笔记。
3. 批次笔记命名为 `YYYY-MM-DD-n2-题型-题量-items.md`。
4. 把批次笔记加入 `mistakes/by-type/` 下对应题型索引。
5. 可复用语法点整理到 `grammar/`。
6. 词汇、搭配、近义辨析整理到 `vocabulary/`。
7. 批次笔记和相关主题笔记互相链接。

复习入口：[[mistakes/README|mistakes/README.md]]。
