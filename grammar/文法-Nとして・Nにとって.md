# Nとして / Nにとって

| 表达 | 意思 | 判断点 |
|---|---|---|
| Nとして | 作为……、以……身份 | 身份、立场、资格 |
| Nにとって | 对……来说 | 后面多接评价、利害、重要性 |

例句:

- 彼は選手としてではなく、コーチとして参加した。
- 学生にとって、この辞書は使いやすい。
