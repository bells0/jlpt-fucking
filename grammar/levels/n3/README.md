# N3 语法索引

[[grammar/levels/README|← 返回分级语法索引]]｜[[grammar/README|返回文法总索引]]

N3 后续整理放在这里。这个等级是进入 N2 前最关键的桥：句子会变长，连接、评价、原因、让步和书面表达会明显增加。

## 预定模块

| 模块 | 重点 |
|---|---|
| 连接表达 | `ために`、`ように`、`うちに`、`間に`、`かわりに` |
| 评价表达 | `はず`、`べき`、`わけ`、`ところ` |
| 变化和趋势 | `ようになる`、`ことになる`、`ていく`、`てくる` |
| 让步和限制 | `ても`、`としても`、`ばかり`、`だけでなく` |
| 传闻和样态 | `そうだ`、`ようだ`、`みたいだ`、`らしい` |
| 复合句阅读 | 修饰节、引用、长句骨架 |
| N2 前置弱点 | 与 N2 文法错题反复相关的 N3 基础 |
