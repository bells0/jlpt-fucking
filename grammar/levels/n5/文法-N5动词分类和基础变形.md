# N5 动词分类和基础变形

[[grammar/levels/n5/README|← 返回 N5 语法索引]]

日语 N5 的动词变形，核心先掌握 **3类动词 + 6种常用变形** 就够了。

## 1. 日语动词分 3 类

### 一类动词：五段动词

特点：词尾多为 **う、く、ぐ、す、つ、ぬ、ぶ、む、る**。

例：

| 原形 | 意思 |
|---|---|
| 書く | 写 |
| 飲む | 喝 |
| 話す | 说 |
| 買う | 买 |
| 帰る | 回去 |

注意：不是所有 `る` 结尾都是二类，比如 **帰る、入る、走る** 是一类。

### 二类动词：一段动词

特点：多为 `る` 结尾，而且前一个假名常是 **い段 / え段**。

例：

| 原形 | 意思 |
|---|---|
| 食べる | 吃 |
| 見る | 看 |
| 起きる | 起床 |
| 寝る | 睡觉 |
| 教える | 教 |

### 三类动词：不规则动词

只有两个核心：

| 原形 | 意思 |
|---|---|
| する | 做 |
| 来る（くる） | 来 |

## 2. N5 常见动词变形总表

以这几个词为例：

| 类别 | 原形 |
|---|---|
| 一类 | 書く |
| 二类 | 食べる |
| 三类 | する、来る |

## 3. ます形：礼貌表达

意思：做某事。

### 变形规则

| 类别 | 规则 | 例子 |
|---|---|---|
| 一类 | 词尾う段 → い段 + `ます` | 書く → 書きます |
| 二类 | 去掉 `る` + `ます` | 食べる → 食べます |
| 三类 | 特殊记忆 | する → します；来る → 来ます |

例句：

> 私はご飯を食べます。  
> 我吃饭。

## 4. ません：礼貌否定

意思：不做某事。

| 原形 | ます形 | 否定 |
|---|---|---|
| 書く | 書きます | 書きません |
| 食べる | 食べます | 食べません |
| する | します | しません |
| 来る | 来ます | 来ません |

例句：

> コーヒーを飲みません。  
> 我不喝咖啡。

## 5. ました：礼貌过去

意思：做了某事。

| 原形 | ます形 | 过去 |
|---|---|---|
| 書く | 書きます | 書きました |
| 食べる | 食べます | 食べました |
| する | します | しました |
| 来る | 来ます | 来ました |

例句：

> 昨日、映画を見ました。  
> 昨天看了电影。

## 6. ませんでした：礼貌过去否定

意思：过去没有做某事。

| 原形 | 过去否定 |
|---|---|
| 書く | 書きませんでした |
| 食べる | 食べませんでした |
| する | しませんでした |
| 来る | 来ませんでした |

例句：

> 昨日、学校へ行きませんでした。  
> 昨天没去学校。

## 7. て形：N5 非常重要

て形常用于：

1. 请求：`〜てください`
2. 连接动作：`〜て、〜`
3. 正在做：`〜ています`

### 一类动词て形规则

一类动词最麻烦，要按词尾记。

| 原形词尾 | て形变化 | 例子 |
|---|---|---|
| う、つ、る | って | 買う → 買って；待つ → 待って；帰る → 帰って |
| む、ぶ、ぬ | んで | 飲む → 飲んで；遊ぶ → 遊んで；死ぬ → 死んで |
| く | いて | 書く → 書いて |
| ぐ | いで | 泳ぐ → 泳いで |
| す | して | 話す → 話して |

特殊：

| 原形 | て形 |
|---|---|
| 行く | 行って |

### 二类动词て形

规则：去掉 `る` + `て`。

| 原形 | て形 |
|---|---|
| 食べる | 食べて |
| 見る | 見て |
| 起きる | 起きて |
| 寝る | 寝て |

### 三类动词て形

| 原形 | て形 |
|---|---|
| する | して |
| 来る | 来て |

例句：

> ちょっと待ってください。  
> 请稍等。

> ご飯を食べて、学校へ行きます。  
> 吃饭后去学校。

## 8. ない形：普通否定

意思：不做某事。

### 一类动词ない形

规则：词尾う段 → あ段 + `ない`。

| 原形 | ない形 |
|---|---|
| 書く | 書かない |
| 飲む | 飲まない |
| 話す | 話さない |
| 帰る | 帰らない |

特殊注意：

| 原形 | ない形 |
|---|---|
| 買う | 買わない |

不是 `買あない`，而是 **買わない**。

### 二类动词ない形

规则：去掉 `る` + `ない`。

| 原形 | ない形 |
|---|---|
| 食べる | 食べない |
| 見る | 見ない |
| 起きる | 起きない |

### 三类动词ない形

| 原形 | ない形 |
|---|---|
| する | しない |
| 来る | 来ない |

例句：

> 朝ご飯を食べない。  
> 不吃早饭。

## 9. た形：普通过去

意思：做了某事。

た形和て形规则几乎一样，把 **て / で** 换成 **た / だ**。

### 一类动词た形

| 原形词尾 | た形变化 | 例子 |
|---|---|---|
| う、つ、る | った | 買う → 買った；待つ → 待った；帰る → 帰った |
| む、ぶ、ぬ | んだ | 飲む → 飲んだ；遊ぶ → 遊んだ |
| く | いた | 書く → 書いた |
| ぐ | いだ | 泳ぐ → 泳いだ |
| す | した | 話す → 話した |

特殊：

| 原形 | た形 |
|---|---|
| 行く | 行った |

### 二类动词た形

规则：去掉 `る` + `た`。

| 原形 | た形 |
|---|---|
| 食べる | 食べた |
| 見る | 見た |
| 起きる | 起きた |

### 三类动词た形

| 原形 | た形 |
|---|---|
| する | した |
| 来る | 来た |

例句：

> 昨日、ラーメンを食べた。  
> 昨天吃了拉面。

## 10. 动词原形：辞书形

辞书形就是字典里的形式，也就是原形。

例：

| ます形 | 辞书形 |
|---|---|
| 書きます | 書く |
| 食べます | 食べる |
| します | する |
| 来ます | 来る |

N5 常见用法：

### 〜ことができます

表示“会 / 能”。

> 日本語を話すことができます。  
> 会说日语。

### 〜前に

表示“在……之前”。

> 寝る前に、歯を磨きます。  
> 睡觉前刷牙。

## 11. N5 优先记忆顺序

建议按这个顺序学：

1. **ます形**：最基础礼貌表达
2. **ません / ました / ませんでした**：礼貌否定、过去
3. **て形**：请求、连接、正在进行
4. **ない形**：普通否定
5. **た形**：普通过去
6. **辞书形**：接语法，比如 `〜ことができます`、`〜前に`

## 12. 最核心口诀

### 一类动词

看词尾变化：

> 書く → 書きます  
> 書く → 書いて  
> 書く → 書かない  
> 書く → 書いた

### 二类动词

基本都是：

> 去掉 `る` + `ます / て / ない / た`

例：

> 食べる → 食べます  
> 食べる → 食べて  
> 食べる → 食べない  
> 食べる → 食べた

### 三类动词

死记：

| 原形 | ます形 | て形 | ない形 | た形 |
|---|---|---|---|---|
| する | します | して | しない | した |
| 来る | 来ます | 来て | 来ない | 来た |

> [!tip]
> N5 阶段最重要的是：**先会判断动词类别，再背て形和ない形。** 这两个是后面语法的基础。
