# N1 语法索引

[[grammar/levels/README|← 返回分级语法索引]]｜[[grammar/README|返回文法总索引]]

N1 语法后续整理放在这里。N1 的重点不是“句型看起来复杂”本身，而是书面语、抽象评价、强限定、让步、逆接和固定搭配的语感边界。

## 预定模块

| 模块 | 重点 |
|---|---|
| 书面判断 | `にほかならない`、`に相違ない`、`までもない` |
| 强限定・强调 | `をおいて`、`ならでは`、`たりとも`、`すら` |
| 让步・逆接 | `とはいえ`、`ものを`、`ながらも`、`といえども` |
| 原因・结果 | `ゆえに`、`ばこそ`、`始末だ` |
| 时间・场面 | `や否や`、`なり`、`そばから`、`が早いか` |
| 固定搭配 | 考试常见高书面度表达和搭配限制 |
| 易混辨析 | 和 N2/N3 表达意思相近但语气更硬的句型 |
