# JLPT 分级语法索引

[[grammar/README|← 返回文法总索引]]｜[[README|返回总导航]]

这个目录用来按 JLPT 等级整理 N5 → N1 的语法。N5/N4/N3 用来补基础，N2/N1 用来承接当前目标和后续高级语法复习。

## 分级入口

| 等级 | 入口 | 当前状态 | 重点 |
|---|---|---|---|
| N5 | [[grammar/levels/n5/README\|N5 语法索引]] | 已建立总览 | 助词、です形、动词基础活用、て形、基础句型 |
| N4 | [[grammar/levels/n4/README\|N4 语法索引]] | 待整理 | 条件、授受、可能、意志、基础敬语 |
| N3 | [[grammar/levels/n3/README\|N3 语法索引]] | 待整理 | 书面连接、评价表达、复合句、N2 前置弱点 |
| N2 | [[grammar/levels/n2/README\|N2 语法索引]] | 已连接现有索引 | N2 句型、文章语法、错题复盘 |
| N1 | [[grammar/levels/n1/README\|N1 语法索引]] | 待整理 | 高书面度表达、强限定、让步、抽象评价 |

## 整理规则

1. 每个等级先保留一个 `README.md` 总览，按功能查语法。
2. 以后遇到不稳的语法，再拆成单独词条，放到对应等级目录下。
3. 单独词条沿用 [[templates/knowledge_point|知识点模板]]，但 `level` 改成对应等级。
4. 已经在错题中反复影响判断的语法，要从错题页反链到对应等级索引或原子词条。
