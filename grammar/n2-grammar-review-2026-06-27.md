# N2 文法复习 2026-06-27

来源：[[mistakes/2026/06/2026-06-27-n2-bunpou-14-items|N2 文法错题 14 题]]

## 快速复习表

| 句型 / 表达 | 意思 | 题目中的信号 | 例句 |
|---|---|---|---|
| `NさえVない` | 连……都不 | 极端小事也做不到 | `水に顔をつけることさえできなかった。` |
| `まず無理だろう` | 恐怕不可能 | 对实现可能性的判断 | `一日で終わらせるのはまず無理だろう。` |
| `〜てからでないと〜ない` | 不先……就不能…… | 后项是否定 | `返してからでないと借りられない。` |
| `〜のかというようなN` | “是否……”这样的 N | 批判、质疑、疑问内容 | `意味があるのかというような意見` |
| `〜わけではない` | 并不是…… | 部分否定 | `完全に治ったわけではない。` |
| `Vます形 + がたい` | 难以…… | 强烈印象、心理上难忘 | `忘れがたい感動` |
| `もう少しで〜ところだった` | 差点就…… | 事情险些发生 | `もう少しで洗濯するところだった。` |
| `〜てしまうことがある` | 有时不由得…… | 不受控制、结果不如预期 | `自分のほうが寝てしまうことがある。` |
| `するだけしてみる` | 能试的先试试看 | 建议挑战、尝试 | `チャレンジするだけしてみたら？` |
| `〜にでもなったような気分` | 像变成……似的心情 | 比喻体验 | `お姫様にでもなったような気分` |
| `〜を気にするあまり` | 过于在意……以至于 | 后项多为消极结果 | `人目を気にするあまり言えない。` |
| `Nも必要` | N 也必要 | 前文已列举其他必要条件 | `体力も必要だ。` |
| `〜てしまった` | 不由得……了 | 感情自然流露 | `感動してしまった。` |
| `Vてよかった` | 做了……真好 | 对实际体验的评价 | `やってみて本当に良かった。` |

## 易混辨析

| 易混点 | 该选哪个 | 判断法 |
|---|---|---|
| `さえ` / `ばかり` | 连小事都做不到选 `さえ` | `ばかり` 是“光是、净是”。 |
| `たとえ` / `まず` | 判断“不可能”选 `まず` | `たとえ` 后面通常需要 `〜ても`。 |
| `てからでないと` / `てはじめて` | 后项否定选 `てからでないと` | `はじめて` 强调“做了 A 才第一次 B”。 |
| `わけではない` / `にすぎない` | 部分否定选 `わけではない` | `にすぎない` 是“只不过”。 |
| `てしまった` / `ていた` | 感情涌出选 `てしまった` | `ていた` 只是持续状态。 |
| `やってみて` / `やってみたら` | 实际尝试后的评价选 `やってみて` | `たら` 是假设条件。 |

1. 怖くて水に顔をつけること（　）できなかった。
2. 完全に治った（　）が、日常生活には困らない。
