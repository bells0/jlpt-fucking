# 敬语：先判断动作主语

### 意思

- `お + Vます形 + する`: 自谦语，说“我/己方做”。
- `お + Vます形 + になる`: 尊敬语，说“对方/客户/老师做”。

### 例句

- 解約の理由をお聞きしてもよろしいでしょうか。
- 先生はその話をお聞きになりましたか。

### 易错点

| 场景 | 应选 | 理由 |
|---|---|---|
| 店员问客人理由 | `お聞きする` | 问的人是店员自己 |
| 客户来到公司 | `おいでになる` | 来的人是客户，要抬高客户 |
| 自己去拜访客户 | `伺う` | 自己动作，用自谦 |
| 自己来了 | `参る` | 自己动作，用自谦 |
