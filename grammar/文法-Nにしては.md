# Nにしては

### 意思

- “以……来说”，后面给出和一般预想不同的评价。

### 接续

- `名詞 + にしては`
- `普通形 + にしては`

### 例句

- 初めてにしては、なかなか上手だった。
- 子どもにしては、説明がとてもわかりやすい。

### 易错点

- 后面常接评价词：`上手だ`、`詳しい`、`よくできた`。
- `なかなか` 可以修饰正面评价，表示“相当、挺”。
