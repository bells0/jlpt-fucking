# 反省

| 项目 | 内容 |
|---|---|
| 読み方 | はんせい |
| 词性 | 名词・する动词 |
| 核心意思 | 反思自己的错误、不足或失败 |

常见搭配：

- `自分の行動を反省する`
- `準備不足を反省する`
- `深く反省する`
- `反省点`

易混：

| 词 | 用法 |
|---|---|
| `反省する` | 反思自己的问题 |
| `振り返る` | 回顾过去，不一定有错误 |
| `思い出す` | 想起、回忆 |
| `懐かしむ` | 怀念 |
