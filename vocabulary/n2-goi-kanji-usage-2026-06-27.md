# N2 文字・語彙复习 2026-06-27

来源: [[mistakes/2026/06/2026-06-27-n2-goi-12-items|N2 文字・語彙错题 12 题]]

## 快速复习表

| 项目 | 读音 | 核心意思 | 常见搭配 | 易错提醒 |
|---|---|---|---|---|
| 実践 | じっせん | 实践、实行 | `理論を実践する`、`すぐ実践できる` | 不读 `じっげん`；区别 `実験（じっけん）`。 |
| 避難 | ひなん | 避难、逃难 | `安全な場所に避難する` | 不写 `避離`。 |
| 敬う | うやまう | 尊敬 | `先祖を敬う`、`年上の人を敬う` | `拝む` 是拜、祈祷。 |
| 受講 | じゅこう | 听课、参加课程 | `講座を受講する`、`受講の申し込み` | 学生接受课程，用 `受`。 |
| 宛て | あて | 寄给某人的 | `私宛ての手紙`、`会社宛て` | 不用 `着き`。 |
| 口調 | くちょう | 语气、腔调 | `優しい口調で話す`、`強い口調で言う` | 不是 `音声`。 |
| 修正する | しゅうせいする | 修正、改正 | `表現を修正する`、`間違いを修正する` | 近义是 `直す`。 |
| 徐々に | じょじょに | 慢慢地、逐渐 | `徐々に慣れる`、`徐々に増える` | 近义是 `次第に`，不是 `やっと`。 |
| 剥げる | はげる | 剥落、脱落 | `ペンキが剥げる` | 不是 `こぼれる`。 |
| しぐさ | しぐさ | 举动、动作、姿态 | `印象的なしぐさ` | 近义是 `動作`，不是穿着。 |
| 薄める | うすめる | 稀释、弄淡 | `味を薄める`、`水で薄める` | 温度、音量、水平不用 `薄める`。 |
| 鮮明 | せんめい | 鲜明、清晰 | `鮮明に覚えている`、`鮮明な記憶` | 拒绝、决定更常用 `はっきり`。 |

## 易混辨析

| 易混组 | 区别 | 例句 |
|---|---|---|
| `実践` / `実験` / `実現` | `実践` 是把理论付诸行动；`実験` 是实验；`実現` 是实现。 | `学んだことをすぐ実践した。` |
| `敬う` / `拝む` / `尊ぶ` | `敬う` 是尊敬人；`拝む` 是拜、祈祷；`尊ぶ` 是尊重、珍视价值。 | `先祖を敬う心を持つ。` |
| `受講` / `授業` | `受講` 是学生参加课程；`授業` 是课或上课本身。 | `日本語講座を受講する。` |
| `徐々に` / `やっと` | `徐々に` 强调过程逐渐变化；`やっと` 强调终于达成。 | `新しい職場に徐々に慣れてきた。` |
| `剥げる` / `こぼれる` | `剥げる` 是表面涂层脱落；`こぼれる` 是液体等洒出。 | `古い壁のペンキが剥げている。` |
| `薄める` / `下げる` / `小さくする` | 味道、浓度可 `薄める`；温度和水平 `下げる`；音量 `小さくする`。 | `水を加えて味を薄めた。` |
| `鮮明` / `はっきり` | `鮮明` 偏记忆、画面、印象清晰；`はっきり` 用法更广，可用于决定和拒绝。 | `その場面を鮮明に覚えている。` |

## 场景记忆

- 灾害广播场景: 听到 `安全な場所に避難してください`，重点是离开危险去安全处，写 `避難`。
- 课程报名场景: 主角报名魔法讲座也一样，是 `講座を受講する`，不是 `授講`。
- 信箱场景: 打开信箱看到 `私宛ての手紙`，`宛て` 就像信件上的收件人标签。
- 温柔搭话场景: 安慰害怕的小孩，用 `優しい口調で話しかける`。
- 料理调整场景: 汤太咸，加水 `味を薄める`。温度和音量不要用这个词。

## 回忆练习

1. `実践` 的读音是？
2. `私＿＿の手紙` 表示寄给我的信。
3. `徐々に` 的近义词是 `やっと` 还是 `次第に`？
4. `スープの味を＿＿`，表示把味道调淡。
5. `鮮明に＿＿` 最自然的搭配是什么？

答案: `じっせん` / `宛て` / `次第に` / `薄める` / `覚えている`
