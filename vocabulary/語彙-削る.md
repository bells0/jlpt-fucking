# 削る

### 读音

- `けずる`

### 核心意思

- 把表面一点点削掉。
- 抽象用法是削减预算、时间、分数等。

### 常见搭配

- `鉛筆を削る`
- `木を削る`
- `予算を削る`
- `睡眠時間を削る`

### 易混词

| 词 | 重点 |
|---|---|
| `削る` | 削掉表面或削减数量 |
| `絞る` | 拧、榨、缩小范围 |
| `掘る` | 挖地、挖洞 |
| `握る` | 握住 |

### 例句

- 作品を完成させるために、睡眠時間を削って作業した。
