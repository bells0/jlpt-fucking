# N2 文字・語彙复习 2026-06-25

来源: [[mistakes/2026/06/2026-06-25-n2-goi-13-items|N2 文字・語彙错题 13 题]]

## 快速复习表

| 项目 | 读音 | 核心意思 | 常见搭配 | 易错提醒 |
|---|---|---|---|---|
| 詳細 | しょうさい | 详细 | `詳細に説明する`、`詳細を書く` | 不读 `そうざい`。 |
| 絡まる | からまる | 缠住 | `髪が絡まる`、`コードが絡まる` | 与 `挟まる` 区分：缠绕不是夹住。 |
| 農薬 | のうやく | 农药 | `農薬を使う`、`無農薬野菜` | `農` 是 `のう`。 |
| 志望 | しぼう | 志愿、报考/应聘意向 | `志望校`、`志望理由` | 公司、学校、专业意向用 `志望`。 |
| 散る | ちる | 花落、散开 | `桜が散る`、`花びらが散る` | 不是 `消える`。 |
| 疲労 | ひろう | 疲劳 | `疲労がたまる`、`疲労のせい` | 后一个字是 `労`。 |
| 〜離れ | 〜ばなれ | 远离某事物的趋势 | `読書離れ`、`若者の車離れ` | 社会趋势不用 `抜け`。 |
| もてなす | もてなす | 招待、款待 | `客をもてなす`、`料理でもてなす` | 不是 `おだてる`。 |
| 多大な | ただいな | 巨大的 | `多大な影響`、`多大な迷惑` | `大げさな影響` 不自然。 |
| 溶け込む | とけこむ | 融入 | `クラスに溶け込む`、`職場に溶け込む` | `触れ合う` 是交流，不是融入。 |
| そそっかしい | そそっかしい | 粗心、冒失 | `そそっかしい性格` | 忘带钱包、冒失小错。 |
| 収納する | しゅうのうする | 收纳 | `棚に収納する`、`しまう` | 近义是 `しまう`，不是 `並べる`。 |
| はきはき | はきはき | 说话清楚干脆 | `はきはき答える` | 视觉清楚用 `はっきり`。 |

## 易混辨析

| 易混组 | 区别 | 例句 |
|---|---|---|
| `絡まる` / `挟まる` | `絡まる` 是缠绕；`挟まる` 是夹在两物之间。 | `髪がくしに絡まった。` / `指がドアに挟まった。` |
| `散る` / `消える` | `散る` 是花叶等飘落散开；`消える` 是消失。 | `桜が散った。` |
| `もてなす` / `おだてる` | `もてなす` 是招待；`おだてる` 是奉承、哄。 | `客を料理でもてなした。` |
| `多大な` / `大げさな` | `多大な` 修饰影响、迷惑等程度大；`大げさな` 表夸张。 | `台風は多大な影響を与えた。` |
| `溶け込む` / `触れ合う` | `溶け込む` 是融入群体；`触れ合う` 是接触交流。 | `転校生はクラスに溶け込んだ。` |
| `はきはき` / `はっきり` | `はきはき` 多用于说话、回答；`はっきり` 用于清楚、明确。 | `はきはき答える` / `原因をはっきりさせる` |

## 场景记忆

- 校园转学生: `転校生がクラスに溶け込む`。不是只和同学 `触れ合う`，而是已经融入队伍。
- 招待客人: 父母做料理给客人吃，是 `客をもてなす`。如果说 `おだてる`，就变成“奉承客人”了。
- 樱花镜头: `桜が散る` 是花瓣从树上飘落，适合日剧、动画里春天毕业场景。
- 说话方式: 学生被老师提问时 `はきはきと答える`，远处山看得清楚是 `はっきり見える`。

## 回忆练习

1. `詳細` 的读音是？
2. `客を＿＿` 表示招待客人。
3. `遠くの山が＿＿見える` 应该用 `はきはき` 还是 `はっきり`？
4. `読書＿＿` 表示远离阅读的趋势。

答案: `しょうさい` / `もてなす` / `はっきり` / `離れ`
