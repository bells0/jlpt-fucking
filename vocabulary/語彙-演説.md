# 演説

| 项目 | 内容 |
|---|---|
| 読み方 | えんぜつ |
| 词性 | 名词・する动词 |
| 核心意思 | 在公开正式场合发表主张或方针 |

常见搭配：

- `国会で演説する`
- `街頭演説`
- `選挙演説`
- `演説で述べる`

易混：

| 词 | 用法 |
|---|---|
| `演説` | 政治家、候选人、社长等正式发表主张 |
| `スピーチ` | 毕业典礼、婚礼、活动上的致辞 |
| `挨拶` | 寒暄、致辞、开场讲话 |
