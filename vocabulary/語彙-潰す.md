# 潰す

### 读音

- `つぶす`

### 核心意思

- 把立体物压扁、压坏。
- 也可表示毁掉组织、计划，或打发时间。

### 常见搭配

- `空き缶を潰す`
- `箱を潰す`
- `店を潰す`
- `時間を潰す`

### 易混词

| 场景 | 更自然的词 |
|---|---|
| 玻璃杯摔坏 | `割れる`、`壊れる` |
| 衣服收进柜子 | `畳む` |
| 纸张撕碎 | `破る`、`細かく破る` |

### 例句

- 電車を待つ間、駅前の本屋で時間を潰した。
