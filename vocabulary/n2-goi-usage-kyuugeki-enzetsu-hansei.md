# 語彙用法：急激・演説・反省

标签: `#語彙` `#jlpt-n2` `#错题`

来源错题：[2026-04-29 N2 文法・語彙错题 6 题](../mistakes/2026/04/2026-04-29-n2-bunpou-goi-06-items.md)

## 急激

| 项目 | 内容 |
|---|---|
| 読み方 | きゅうげき |
| 词性 | ナ形容词 |
| 核心意思 | 变化突然且剧烈 |

常见搭配：

- `急激に増加する`
- `急激に減少する`
- `急激に変化する`
- `急激な変化`

不适合：

- 粉丝“迅速围上来”一般不用 `急激に取り囲む`。
- 这种动作更自然说 `すぐに`、`一斉に`。

## 演説

| 项目 | 内容 |
|---|---|
| 読み方 | えんぜつ |
| 词性 | 名词・する动词 |
| 核心意思 | 在公开正式场合发表主张或方针 |

常见搭配：

- `国会で演説する`
- `街頭演説`
- `選挙演説`
- `演説で述べる`

易混：

| 词 | 用法 |
|---|---|
| `演説` | 政治家、候选人、社长等正式发表主张 |
| `スピーチ` | 毕业典礼、婚礼、活动上的致辞 |
| `挨拶` | 寒暄、致辞、开场讲话 |

## 反省

| 项目 | 内容 |
|---|---|
| 読み方 | はんせい |
| 词性 | 名词・する动词 |
| 核心意思 | 反思自己的错误、不足或失败 |

常见搭配：

- `自分の行動を反省する`
- `準備不足を反省する`
- `深く反省する`
- `反省点`

易混：

| 词 | 用法 |
|---|---|
| `反省する` | 反思自己的问题 |
| `振り返る` | 回顾过去，不一定有错误 |
| `思い出す` | 想起、回忆 |
| `懐かしむ` | 怀念 |

## 做题提醒

語彙用法题先看“搭配对象”：

- 变化快不快：`急激に増加する`
- 场合是否公开正式：`国会で演説する`
- 是否反思自己的错：`準備不足を反省する`
