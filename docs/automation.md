# 错题入库自动化

标签: `#错题` `#自动化` `#jlpt-n2`

## 用途

这个脚本负责把“截图进入错题库”的重复步骤自动化：

1. 从项目根目录寻找 `Screenshot_*.jpg`、`Screenshot_*.png` 等截图。
2. 按日期归档到 `mistakes/assets/YYYY-MM-DD/`。
3. 生成当天错题批次模板。
4. 输出索引更新草稿和后续整理提醒。

所有错题都先完整保留题干和选项。语法解释、词汇辨析、错因分析、例句和复习题只能放在原题记录之后。文法题和句子题还要优先补整句翻译、整句拆解，方便 N2 学习者真正看懂句子。

## 基本用法

在项目根目录运行：

```bash
python scripts/new_mistake_batch.py --date 2026-04-29 --type bunpou-goi --count 6
```

常用题型：

| 参数 | 含义 |
|---|---|
| `bunpou` | 文法 |
| `goi` | 語彙 |
| `kanji` | 漢字 |
| `bunpou-goi` | 文法・語彙混合 |
| `bunpou-kumitate` | 文の組み立て |
| `reading` | 読解 |
| `listening` | 聴解 |

## 预览模式

不想马上移动截图时，先运行：

```bash
python scripts/new_mistake_batch.py --date 2026-04-29 --type bunpou-goi --count 6 --dry-run
```

`--dry-run` 只显示将要执行的动作，不移动图片，也不创建批次文件。

## 原题记录检查

整理完错题后运行：

```bash
python scripts/check_mistake_originals.py
```

如果某道题没有先写「原题完整记录（不要加工）」、选项、你的答案、正解，检查会失败。失败时先补原题，不要继续写解析。

## 推荐流程

1. 把错题截图放到项目根目录。
2. 运行脚本生成批次模板。
3. 打开生成的 `mistakes/YYYY/MM/YYYY-MM-DD-n2-题型-题量-items.md`。
4. 我根据截图补全：
   - 原题完整记录
   - 题干
   - 全部选项
   - 你的答案
   - 正解
   - 整句翻译
   - 整句拆解
   - 中文翻译
   - 高频考点
   - 错因分析
   - 例句
   - 迷你复习题
5. 根据脚本输出的索引草稿，更新错题索引和题型索引。

脚本会分别提示：

- `mistakes/README.md` 的批次列表链接。
- `mistakes/by-type/题型/README.md` 的题型索引链接。
- 需要沉淀的 `grammar/`、`vocabulary/`、`kanji/` 主题笔记。

## 原题完整保留规则

这是所有题目整理的基础：

1. 先保留原题，不先总结。
2. 题干和选项都要完整写下来。
3. 不改写题干，不把选项合并成解释。
4. 你的答案和正解单独记录。
5. 解析、翻译、语法点、词汇点、漢字读音总结都放在原题之后。
6. 文法题、句子题、阅读中的关键句，优先补整句翻译和整句拆解。

漢字题尤其要保留：

- 题干
- 划线词
- 全部选项
- 你的答案
- 正解

示例：

```md
#### 原题完整记录（不要加工）

- 题干:
- 划线词:

#### 选项

1.
2.
3.
4.
```

## 排序题模板

当 `--type bunpou-kumitate` 时，脚本会生成排序题专用结构：

```md
#### 原题排序形式

> ＿＿ ＿＿ ★ ＿＿

#### 选项

1.
2.
3.
4.

#### 正确顺序

- 顺序:
- ★答案:

#### 还原过程
```

这样复习时会先回到题目原来的排序形式，再看完整句，避免只记住答案而不会重新做题。

## 参数说明

| 参数 | 是否常用 | 说明 |
|---|---|---|
| `--date` | 常用 | 批次日期，格式 `YYYY-MM-DD`。不填时会尝试从截图文件名推断。 |
| `--type` | 必填 | 题型。 |
| `--count` | 常用 | 题数。不填时默认使用本次归档截图数量。 |
| `--level` | 少用 | 默认 `n2`。 |
| `--title` | 少用 | 自定义批次标题。 |
| `--source-dir` | 少用 | 截图来源目录，默认项目根目录。 |
| `--dry-run` | 常用 | 预览模式。 |
| `--force` | 谨慎 | 覆盖已有批次模板。 |

## 注意

- 脚本默认不会覆盖已有批次文件。
- 如果目标截图目录已有同名图片，会自动加编号，避免覆盖。
- 生成模板后，不会自动判断正解或解释语法点；这一步仍需要认真整理。
